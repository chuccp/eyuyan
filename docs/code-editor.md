# 代码编辑器与编程体验

易语 Studio 的代码窗口吸收 Visual Basic 与易语言的连续代码布局。`.yyc` 打开后默认显示“经典视图”：每个子程序先显示一张紧凑的方法声明表，紧接其下编辑连续执行代码。执行语句不进入表格。

工作区采用现代 IDE 布局：应用图标、主菜单、当前文档标题和窗口按钮共用一条自定义顶部操作栏，不再显示独立的系统标题栏；窗口仍支持拖动、缩放、双击最大化、最小化和还原。文档标签位于编辑器顶部，标签下方显示“项目 › 目录 › 文件 › 过程”的路径面包屑。左侧固定显示真实项目目录树；右侧保留程序数据和属性工具窗口。窗口组件箱只在窗体设计器中显示。当前对象和过程仍保留在代码窗口工具栏。

## 基础编辑能力

纯代码编辑器和经典视图正文共用以下能力：

- 输入字母、中文、下划线或 `.` 时自动弹出上下文补全，`Ctrl+Space` 可手动打开。
- 补全包含内置命令、语言关键字、用户子程序、窗体控件、控件属性、当前子程序参数和局部变量。
- 打开函数括号后，底部提示栏显示完整签名和当前参数序号。
- 将光标移到命令、函数或变量上按 `F1` 查看帮助。
- `()`、`[]`、`{}`、`""`、`“”` 自动配对；选中文本后输入左括号可直接包围。
- 按块缩进、代码折叠、当前行高亮、搜索、撤销和重做。
- `Ctrl+/` 切换注释，`Ctrl+D` 复制当前行，`Ctrl+Shift+K` 删除当前行。

## 经典视图

代码视图参考经典易语言和 Ecode 的结构：程序集、子程序、参数和局部变量使用紧贴正文的紧凑小表；正文保持连续编辑。左侧流程边栏用连续竖线、分支横线和方向箭头表达 `如果`、`否则`、循环和异常块层级，流程线不进入代码文本。

默认代码窗口的结构：

```text
对象：[主窗口（窗口）]  过程：[保存按钮_被单击] [经典视图] [纯代码] [格式化]
────────────────────────────────────────────────────
┌────────────┬──────────┬────┬────┬────────────┐
│ 子程序名    │ 返回值类型│公开│易包│ 备注        │
├────────────┼──────────┼────┼────┼────────────┤
│ _保存按钮_被单击         │    │ 假 │假│保存按钮·被单击│
└────────────┴──────────┴────┴────┴────────────┘
    如果 修剪(姓名输入框.文本) == "" 则
        提示("请先填写姓名")
        返回
    结束如果
```

交互规则：

- 对象下拉框列出当前窗体和带有事件的控件。
- 过程下拉框只列出当前对象的事件过程或通用子程序。
- 选择对象或过程后直接跳到对应代码。
- 方法小表从代码画布左侧缩进，右侧仍属于同一连续画布，不额外铺底色块。
- 经典视图采用易语言式连续画布，不显示行号；纯代码模式显示行号和折叠栏。
- 两种代码模式都提供语法着色、补全和参数提示。
- 回车沿用块缩进，点击“格式化”按易语块结构统一缩进。
- 参数和局部变量使用紧凑声明表；执行语句不进入表格。
- “纯代码”模式隐藏经典方法表和导航装饰，直接编辑完整源码。
- 导入、保存和事件创建仍使用同一份用户代码，不产生重复源码。

## 事件入口

事件子程序采用统一命名规则：

```text
_按钮1_被单击
_输入框1_内容被改变
__启动窗口_创建完毕
```

在窗体设计器双击控件，会：

1. 在用户 `.yyc` 中创建缺失的事件入口；
2. 保留同名函数的全部现有内容；
3. 自动生成 `.Designer.yyc` 关系映射；
4. 打开用户代码并定位到事件。

自动关系文件是只读的易语声明代码，不包含 XML。用户逻辑和事件实现只保存在 `.yyc`；`@id/...` 由关系文件独占，用户代码直接写 `保存按钮.文本`、`窗口.标题`。

在 `导入包 "` 后触发补全时，编辑器只显示 SDK 中的系统包；普通代码位置不会把包名混入关键字候选。
在 `引入 "` 后触发补全时，编辑器扫描当前工程 `Sources/` 下的源码目录，给出 `项目包名.子目录` 候选；窗体目录不进入目录包候选。

## 左侧项目目录

左侧按磁盘目录展示项目：

```text
项目
└─ examples
   ├─ MCP资源演示/
   │  ├─ Sources/
   │  │  └─ Forms/
   │  └─ Resources/
   └─ 示例.yyproj
```

双击文件夹展开或折叠，双击 `.yyx`、`.yyc`、`.yyproj` 等文件打开对应编辑器。

右侧工具窗口：

```text
右侧
├─ 程序数据
└─ 属性
```

“程序数据”保留窗体三件套、程序集、常量表和资源表等语义结构。窗口组件箱只在窗体设计器打开时出现在最右侧。

语言语法、SDK 包和内置命令参考不再占用右侧工具窗。选择
“帮助 → 易语开发文档”可打开按快速开始、语言语法、系统 SDK、命令参考和
编辑器分类的内置文档，并支持全文搜索。

## 源码 `.yyc`

```text
.程序集 主窗口代码
导入包 "系统.基础"
导入包 "系统.文本"

子程序 _保存按钮_被单击()
    如果 修剪(姓名输入框.文本) == "" 则
        提示("请先填写姓名。")
        返回
    结束如果
    输出("已保存")
结束子程序
```

`.yyc` 在磁盘上始终是易语源码。IDE 打开文件时解析成内存结构，用于识别子程序、条件、循环、赋值目标和事件入口；保存时再校验并写回源码，不生成 XML。

## 组件感知补全

用户代码与窗体关联后：

- 补全优先列出当前窗体真实控件名。
- 补全同时提供 `窗口` 和当前窗体名作为窗口上下文。
- 输入 `保存按钮.` 只列出该控件支持的属性。
- 事件徽标显示对应控件和事件。
- 双击关联控件可跳回设计器并选中控件。
- 赋值目标可以直接从真实控件属性中选择。

属性候选来自 `.yyx` 与生成关系，不使用固定演示名单。

按 `F5` 运行工程时，底部“控制台”自动展开，显示编译路径、原生产物大小、启动 PID、标准输出、错误输出和退出码。

## 代码补全与提示

- `Ctrl+Space`：打开补全，可在 Studio 配置中修改。
- `F1`：显示当前控件、属性、内置命令或用户子程序的帮助，可在 Studio 配置中修改。
- 输入函数左括号后显示签名、参数序号和说明。
- 选择 `如果`、`计次循环`、`遍历`、`尝试`、`子程序` 等补全项会插入完整代码块并选中占位名称。
- 行号、列号和跨文件诊断用于定位真实源码位置。

## 编程体验原则

- 用户代码最高优先级；工具不得静默覆盖。
- 事件建立路径应是一次双击，而不是手工写绑定。
- 常用操作可完全键盘完成。
- 布局保持紧凑，减少固定面板对代码空间的挤压。
- 自动生成和用户可编辑区域必须在界面与文件系统中都能一眼区分。

## 当前边界

- 补全按当前文件、当前窗体和当前子程序分析，跨模块符号数据库仍不完整。
- 参数提示已覆盖内置函数、用户子程序和易语言方法体，后续继续加入重载与类型高亮。

界面交互参考了经典易语言 IDE 和 [Ecode](https://github.com/imzhangshirong/Ecode) 的静态代码视图组织方式；Studio 使用 AvalonEdit 重新实现编辑、补全、折叠和流程边栏。
- 控件成员目前是运行期对象，静态强类型成员生成仍在路线图中。
