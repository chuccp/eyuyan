# 代码编写与组件关联

易语 Studio 的编程界面对齐易语言官方教程(<https://www.dywt.com.cn/help/day/>):左侧“工作与状态组合夹”(支持库|程序|属性,夹标签在底部)、中央设计中心、右侧“窗口组件箱”、底部“提示、输入出组合夹”(提示|输出|调用表|查改变量)。代码编辑器采用官方表格化结构。

## 表格化代码编辑器

打开 `.yyc` 文件后显示表格结构(对齐官方 img056):

1. **程序集表**:`窗口程序集名 | 备注`。
2. **子程序表**:`子程序名 | 返回值类型 | 公开 | 备注`,每行左侧 `＋/－` 折叠展开。
3. 展开后依次是**参数表**(`变量名|类型|参考|可空|数组|默认值|备注`,末行回车可插入参数)、**局部变量表**(`变量名|类型|静态`,`Ctrl+L` 插入)与**代码体**。
4. 代码行显示全角运算符(如 `标签1.标题 ＝ "我爱易语言！"`);空格或双击进入行编辑,未确认显示“草稿”,回车确认、Esc 取消,F1 在提示夹显示帮助;容器语句可 `＋/－` 折叠。

## 事件处理子程序命名(官方规则)

事件子程序按官方格式命名:`_` + 窗口单元名称 + `_` + 事件名称,例如 `_按钮1_被单击`、`_输入框1_内容被改变`、`__启动窗口_创建完毕`。以 `_` 开头的名称具有特定意义:`_启动窗口` 在程序启动后自动载入。

在窗体设计器双击控件生成默认事件;或在“属性”夹底部的“在此处选择加入事件处理子程序”下拉框中选择事件,已实现的事件标注 ✓。

## 从程序夹进入代码

左侧“程序”夹按官方“程序数据”树组织:

```text
程序数据
├─ 全局变量        (双击打开数据表)
├─ 自定义数据类型
├─ Dll命令
├─ 窗口
│  └─ _启动窗口    (双击打开窗体设计器)
├─ 程序集          (无窗口 .yyc 模块)
├─ 常量表...
└─ 资源表
   ├─ 图片或图片组...
   └─ 声音...
```

## `.yyc` 结构化代码

新项目默认使用 UTF-8 XML 结构化源码，文件中直接保存子程序、参数和命令字段：

```xml
<代码 格式版本="1" 名称="主窗体代码">
  <子程序 名称="姓名输入框_文本改变">
    <赋值 目标="标题标签.文本"
          运算符="="
          值="&quot;你好，&quot; + 姓名输入框.文本" />
  </子程序>
  <子程序 名称="保存按钮_被单击">
    <如果 条件="修剪(姓名输入框.文本) == &quot;&quot;">
      <调用 值="提示(&quot;请先填写客户姓名。&quot;)" />
      <返回 />
    </如果>
    <调用 值="输出(&quot;已保存&quot;)" />
  </子程序>
</代码>
```

IDE 会把 XML 命令转换为可展开的“结构化代码”视图。选择“赋值”步骤后，可以直接从当前窗体组件列表中设置 `控件.属性` 目标，不需要记忆组件名称。

项目源码、自动生成的事件代码和项目内新建源码统一使用 `.yyc`。

## 打开文件后的二次处理

IDE 不会把 `.yyc` 原样放进普通文本编辑器：

```text
.yyc XML ───────────────> 格式校验 ─> 代码模型 ─> 结构化命令树
                                                    ├─ 子程序与参数
                                                    ├─ 条件/循环/异常块
                                                    ├─ 控件属性赋值
                                                    └─ 窗体事件关联
```

打开代码后，左侧“关联窗体”区域会从项目清单和同名 `.yyx` 窗体中获取组件关系：

- 单击事件节点：定位到对应事件子程序。
- 双击控件：打开关联窗体，并在设计器中选中该控件。
- “代码已实现”表示 `.yyx` 事件名能在代码后置中找到同名子程序。
- “代码未实现”表示设计器已声明事件，但代码文件中缺少处理函数。
- 为赋值步骤选择控件属性时，候选组件来自真实窗体，不使用固定演示名单。

事件关联在打开时重新索引，不重复写进 `.yyc`，避免窗体和代码各保存一份事件名字后发生漂移。完整格式说明见 [结构化代码格式](code-format.md)。

## 组件感知补全

结构化视图的表达式字段会识别当前窗体组件：

- 普通补全会优先列出当前窗体的组件名。
- 输入 `组件名.` 后只显示这个组件可写的属性。
- 可用通用属性：`文本`、`名称`、`可见`、`启用`、`选中`、`左`、`上`、`宽`、`高`。
- 属性补全来自实际 `.yyx` 窗体，不是固定演示词表。

示例：

```text
姓名输入框.文本 = "林川"
保存按钮.启用 = 假
客户列表.可见 = 真
```

## 命令与代码块

- `Ctrl+Space`：打开补全。
- 中文命令支持补全，例如 `输出`、`长度`、`JSON生成`。
- 选择 `如果`、`计次循环`、`遍历`、`尝试`、`子程序` 等补全项时，会插入完整代码块，并选中第一个占位名称。
- 输入函数参数时，编辑器底部会显示函数签名、当前参数序号和说明。

## 上下文提示

底部“提示”选择夹显示当前光标处的上下文：

- 控件名：类型、位置、尺寸和可引用属性。
- `控件.属性`：当前属性值及赋值方式。
- 内置命令：签名与功能说明。
- 用户子程序：参数列表和返回类型。

按 `F1` 可随时切换到提示面板。

## 当前边界

- 补全目前按当前文件与当前窗体分析，尚未实现完整的跨模块符号数据库。
- 参数提示会识别函数签名，但尚未对所有重载和能力要求进行高级约束。
- 步骤树已是结构化编辑主体，但表达式、条件和值仍使用中文文本语法，并非完全表单化的命令表格。
- 损坏的 `.yyc` 会进入文本修复模式并报告行列；修复后重新打开即可回到结构化视图。
