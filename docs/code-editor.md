# 代码编写与组件关联

易语 Studio 的代码编辑器围绕“窗体组件 + 事件子程序 + 属性访问”设计，避免代码窗口和可视化设计器成为两套互不相关的文件。

## 从组件进入代码

解决方案资源管理器按以下层级展开：

```text
主窗体.yyx
├─ 主窗体.ey
└─ 组件 (N)
   ├─ 保存按钮 · 按钮
   │  └─ ƒ 单击 · 保存按钮_被单击
   └─ 姓名输入框 · 输入框
      └─ ƒ 文本改变 · 姓名输入框_文本改变
```

- 单击组件节点：打开窗体设计器并选中该组件。
- 在窗体设计器双击组件：创建或打开默认事件。
- 单击事件节点：打开代码后置并定位到对应事件子程序。

## 组件感知补全

编辑当前窗体的代码后置时，代码编辑器会读取窗体组件：

- 普通补全会优先列出当前窗体的组件名。
- 输入 `组件名.` 后只显示这个组件可写的属性。
- 可用通用属性：`文本`、`名称`、`可见`、`启用`、`选中`、`左`、`上`、`宽`、`高`。
- 属性补全来自实际 `.yyx` 窗体，不是固定演示词表。

示例：

```text
姓名输入框.文本 = "林川"
保存按钮.启用 = 假
客户列表.可见 = 真
```

## 命令与代码块

- `Ctrl+Space`：打开补全。
- 中文命令支持补全，例如 `输出`、`长度`、`JSON生成`。
- 选择 `如果`、`计次循环`、`遍历`、`尝试`、`子程序` 等补全项时，会插入完整代码块，并选中第一个占位名称。
- 输入函数参数时，编辑器底部会显示函数签名、当前参数序号和说明。

## 上下文提示

底部“提示”选择夹显示当前光标处的上下文：

- 控件名：类型、位置、尺寸和可引用属性。
- `控件.属性`：当前属性值及赋值方式。
- 内置命令：签名与功能说明。
- 用户子程序：参数列表和返回类型。

按 `F1` 可随时切换到提示面板。

## 当前边界

- 补全目前按当前文件与当前窗体分析，尚未实现完整的跨模块符号数据库。
- 参数提示会识别函数签名，但尚未对所有重载和能力要求进行高级约束。
- 编辑器仍是文本代码加结构化辅助，不是完全折叠式命令表格。
