# 代码编辑器与编程体验

易语 Studio 的代码窗口以 VB6 代码窗口和旧版易语言代码窗口为共同参照。`.yyc` 打开后默认显示“易语言代码”模式：每个子程序先显示一张紧凑的方法声明表，紧接其下编辑连续执行代码。旧的逐行表格编辑器已移除。

工作区采用现代 IDE 布局：文档标签位于编辑器顶部，标签下方显示“项目 › 目录 › 文件 › 过程”的路径面包屑。左侧固定显示真实项目目录树；支持库、程序数据和属性工具窗口位于右侧。窗口组件箱只在窗体设计器中显示。当前对象和过程仍保留在代码窗口工具栏。

## VB / 易语言式代码窗口

默认代码窗口的结构：

```text
对象：[主窗口（窗口）]  过程：[保存按钮_被单击] [易语言代码] [纯代码] [格式化]
────────────────────────────────────────────────────
┌────────────┬──────────┬────┬────┬────────────┐
│ 子程序名    │ 返回值类型│公开│易包│ 备注        │
├────────────┼──────────┼────┼────┼────────────┤
│ _保存按钮_被单击         │    │ 假 │假│保存按钮·被单击│
└────────────┴──────────┴────┴────┴────────────┘
    如果 修剪(姓名输入框.文本) == "" 则
        提示("请先填写姓名")
        返回
    结束如果
```

交互规则：

- 对象下拉框列出当前窗体和带有事件的控件。
- 过程下拉框只列出当前对象的事件过程或通用子程序。
- 选择对象或过程后直接跳到对应代码。
- 方法小表从代码画布左侧缩进，右侧仍属于同一连续画布，不额外铺底色块。
- 易语言代码区采用旧版风格，不显示行号；纯代码模式显示行号和折叠栏。
- 两种代码模式都提供语法着色、补全和参数提示。
- 回车沿用块缩进，点击“格式化”按易语块结构统一缩进。
- 参数和局部变量使用紧凑声明表；执行语句不进入表格。
- “纯代码”模式隐藏易语言方法表和导航装饰，直接编辑完整源码。
- 导入、保存和事件创建仍使用同一份用户代码，不产生重复源码。

## 事件入口

事件子程序采用官方风格：

```text
_按钮1_被单击
_输入框1_内容被改变
__启动窗口_创建完毕
```

在窗体设计器双击控件，会：

1. 在用户 `.yyc` 中创建缺失的事件入口；
2. 保留同名函数的全部现有内容；
3. 自动生成 `.Designer.yyc` 关系映射；
4. 打开用户代码并定位到事件。

自动关系文件是只读的。用户逻辑和事件实现只保存在 `.yyc`。

## 左侧项目目录

左侧按磁盘目录展示项目：

```text
项目
└─ examples
   ├─ 看图软件/
   ├─ 主窗体.yyx
   ├─ 主窗体.Designer.yyc
   ├─ 主窗体.yyc
   └─ 示例.yyproj
```

双击文件夹展开或折叠，双击 `.yyx`、`.yyc`、`.yyproj` 等文件打开对应编辑器。

右侧工具窗口：

```text
右侧
├─ 支持库
├─ 程序数据
└─ 属性
```

“程序数据”保留窗体三件套、程序集、常量表和资源表等语义结构。窗口组件箱只在窗体设计器打开时出现在最右侧。

## 结构化 `.yyc`

```xml
<yy:代码 xmlns:yy="urn:yy-studio:code:1" 格式版本="1" 名称="主窗口代码">
  <yy:子程序 名称="_保存按钮_被单击">
    <yy:如果 条件="修剪(姓名输入框.文本) == &quot;&quot;">
      <yy:调用 值="提示(&quot;请先填写姓名&quot;)" />
      <yy:返回 />
    </yy:如果>
    <yy:调用 值="输出(&quot;已保存&quot;)" />
  </yy:子程序>
</yy:代码>
```

表达式仍使用易语源码语法。结构化存储让 IDE 能稳定识别子程序、条件、循环、赋值目标和事件入口；XML 不是用户写代码时必须面对的主要界面。

## 组件感知补全

用户代码与窗体关联后：

- 补全优先列出当前窗体真实控件名。
- 输入 `保存按钮.` 只列出该控件支持的属性。
- 事件徽标显示对应控件和事件。
- 双击关联控件可跳回设计器并选中控件。
- 赋值目标可以直接从真实控件属性中选择。

属性候选来自 `.yyx` 与生成关系，不使用固定演示名单。

## 代码补全与提示

- `Ctrl+Space`：打开补全。
- `F1`：显示当前控件、属性、内置命令或用户子程序的帮助。
- 输入函数左括号后显示签名、参数序号和说明。
- 选择 `如果`、`计次循环`、`遍历`、`尝试`、`子程序` 等补全项会插入完整代码块并选中占位名称。
- 行号、列号和跨文件诊断用于定位真实源码位置。

## 编程体验原则

- 用户代码最高优先级；工具不得静默覆盖。
- 事件建立路径应是一次双击，而不是手工写绑定。
- 常用操作可完全键盘完成。
- 布局保持紧凑，减少固定面板对代码空间的挤压。
- 自动生成和用户可编辑区域必须在界面与文件系统中都能一眼区分。

## 当前边界

- 补全按当前文件和当前窗体分析，跨模块符号数据库仍不完整。
- 代码块补全和参数提示仍可继续增强。
- 控件成员目前是运行期对象，静态强类型成员生成仍在路线图中。
