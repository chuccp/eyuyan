# 自研 Win64 原生后端

`Yy.Native` 是不依赖 LLVM、Rust、C++ 或 .NET 运行时的原生编译后端。它直接生成 Win64 机器码和 PE32+ 可执行文件，支持控制台程序和 Win32 原生窗口程序。

## 编译流程

```text
yy native 程序.yyc -o 程序.exe
        ↓
易语解析器与语义分析
        ↓
Win64 指令生成
        ↓
PE32+ 节、导入表和机器码写出
        ↓
原生 Windows EXE
```

生成的可执行文件不包含 CLR Header，不依赖 `dotnet`，也不生成其他高级语言源码。当前示例程序体量约为 2–3 KB。

## 隐式主程序

顶层语句直接组成主程序，与 Python 类似：

```text
.程序集 原生示例
导入包 "系统.基础"

变量 总数: 数字 = 0
计次循环 序号 从 1 到 5 步长 1
    总数 = 总数 + 序号
结束循环
输出(总数)
```

不需要 `main` 函数。当前版本也不接受 `.版本` 头，格式版本由工程清单管理。

## 当前能力

- UTF-8 文本和整数常量。
- 数字、文本、逻辑变量与赋值。
- 运行时文本拼接、文本相等比较和堆分配字符串。
- 同类型数组字面量、索引读取、`遍历` 和变量 `追加`。
- 固定形状对象字面量、属性读取和属性赋值。
- UTF-8 文件存在、读取、写入、删除和通配符目录列举。
- `数字(文本)`、`文本(整数)` 原生转换。
- GDI+ 加载 PNG/JPEG 并通过 `STM_SETIMAGE` 显示到 Win32 图片框。
- `+ - * /` 和比较运算。
- `且/&&`、`或/||`、`非/!`。
- `如果`、`当`、`计次循环`、`跳出`、`继续`。
- 最多四个数字/文本参数的基础子程序。
- `输出`、`打印`、`提示` 和文本 `长度`。
- `RegisterClassExW`、`CreateWindowExW`、`ShowWindow` 和原生消息循环。
- Win32 `STATIC`、`BUTTON`、`EDIT`、`COMBOBOX`、`LISTBOX` 控件。
- 按钮单击事件到原生易语子程序的分发。
- `取控件("@id/...").文本/标题` 的动态读取与写入。

## PE 与系统接口

当前 PE 写出器实现：

- DOS/NT 头、PE32+ 可选头和三段节表。
- `.text`、`.rdata`、`.idata`。
- RIP 相对数据和内部代码重定位。
- `kernel32.dll`、`user32.dll` 多 DLL 导入地址表。
- 自定义入口，不链接 C Runtime。

控制台输出直接调用：

```text
GetStdHandle
WriteFile
ExitProcess
```

## 当前边界

完整集合算法、动态键字典、JSON、异常、模块初始化、输入框改变事件和编译期图片资源嵌入尚未进入原生后端。这些程序会停止编译并报告未实现能力，不会回退到 C#/WPF 后端。后续扩展顺序为完整 Win32 控件事件、JSON、异常和编译期资源打包。

## 原生窗体

对 `.yyproj` 或项目目录执行：

```powershell
yy native .\examples\原生窗体 -o .\artifacts\原生窗体.exe
```

编译器从启动窗体生成：

- 窗口类和窗口过程。
- 控件句柄表。
- 隐藏创建控件后再显示窗口。
- `GetMessageW / TranslateMessage / DispatchMessageW` 消息循环。
- `WM_COMMAND` 按钮 ID 到 `.yyc` 事件的映射。
- `SetWindowTextW` 原生文本更新。

## 自举方向

引导阶段由 C# 实现解析器、Win64 后端和 PE 写出器。接口边界保持独立，后续可用易语重写同等模块并由现有编译器编译，逐步实现自举；原生 ABI 和输出格式不依赖引导语言。
