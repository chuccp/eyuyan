# 易语项目结构与代码后置

## 项目而非单文件

易语项目以 `.yyproj` 为根清单，源码、窗体和代码后置文件各自保存，并通过项目清单建立关系。IDE 中的多标签只是编辑视图，项目目录和清单才是构建单元。

新建项目会生成完整目录：

```text
DemoProject/
├─ DemoProject.yyproj
├─ Program.yyc
├─ Forms/
│  ├─ MainForm.yyx
│  └─ MainForm.yyc
└─ Resources/
```

- `Program.yyc`：项目入口结构化源码。
- `Forms/MainForm.yyx`：窗体结构和设计属性，类似 WPF XAML。
- `Forms/MainForm.yyc`：窗体代码后置和事件函数，类似 C# code-behind，但以结构化 XML 保存。
- `Resources`：项目资源目录。

在 IDE 中点击“新建项目”或按 `Ctrl+Alt+N` 创建。新建项目要求选择一个空目录，避免覆盖已有文件。

打开项目后：

- `Ctrl+N` 会在项目根目录新增真实 `.yyc` 结构化源码并写入项目清单。
- “文件 → 项目属性”可修改项目名称、入口源码、启动窗体和输出文件名。
- 项目属性保存后会自动重新加载清单和解决方案资源管理器。

## `.yyproj` 格式

```json
{
  "格式版本": 2,
  "名称": "DemoProject",
  "入口": "Program.yyc",
  "输出": "DemoProject.exe",
  "启动窗体": "MainForm",
  "源码": [
    "Program.yyc",
    "Forms/MainForm.yyc"
  ],
  "窗体": [
    "Forms/MainForm.yyx"
  ],
  "资源": [],
  "引用": []
}
```

字段说明：

| 字段 | 说明 |
|---|---|
| `格式版本` | 当前为 2；仍兼容版本 1 |
| `名称` | 项目名称 |
| `入口` | 启动源码，`Ctrl+F5` 运行该文件 |
| `输出` | 计划生成的可执行文件名称 |
| `启动窗体` | 项目运行后自动打开的窗体类名 |
| `源码` | 项目源码列表，包含代码后置文件 |
| `窗体` | 项目窗体列表 |
| `资源` | 图标、图片、字符串表等资源的相对路径 |
| `引用` | 项目依赖文件 |

所有路径必须位于项目目录内部。入口、源码、窗体和资源不存在时，项目加载会立即给出错误，不会静默忽略。

## 窗体与代码的关系

窗体 XML 根元素通过 `名称` 表示窗体类型，通过 `代码` 指向代码后置文件：

```xml
<窗体 xmlns="urn:yy-studio:form:1"
      名称="主窗口"
      代码="主窗体.yyc"
      标题="客户登记"
      宽="760"
      高="500">
  <输入框 名称="姓名输入框"
          左="126"
          上="96"
          宽="250"
          高="38" />
  <按钮 名称="保存按钮"
        文本="保存客户"
        左="126"
        上="258"
        宽="130"
        高="42"
        单击="保存按钮_被单击" />
</窗体>
```

对应代码后置：

```text
.版本 3
.程序集 主窗体代码

子程序 保存按钮_被单击()
    如果 修剪(姓名输入框.文本) == "" 则
        提示("请先填写客户姓名。")
        返回
    结束如果
    输出("已保存客户：" + 姓名输入框.文本)
    姓名输入框.文本 = "已保存"
结束子程序
```

关系规则：

1. `.yyx` 控件 `名称` 是代码中的对象变量名。
2. 控件 `单击` 属性是事件处理函数名。
3. 项目加载时检查 `代码` 文件是否存在、事件函数是否已定义。
4. 预览窗体时，当前控件文本、启用、可见和复选状态注入事件函数。
5. 事件函数可以读取和修改控件对象；执行结束后状态同步回预览控件。
6. 窗体 `载入` / `关闭` 事件同样映射到代码后置函数。
7. 事件执行有 10 秒超时，避免错误循环卡死整个 IDE。

在窗体设计器中双击按钮，会像 VB/经典易语言一样：

- 自动为按钮设置单击事件名。
- 自动创建或打开代码后置文件。
- 缺失时生成对应事件函数骨架。
- 直接定位到生成的函数。

其他控件同样采用 VB 式默认事件：

- 输入框：双击生成或打开“文本改变”事件。
- 复选框：双击生成或打开“选中改变”事件。
- 下拉框、列表框：双击生成或打开“选择改变”事件。

这形成与 C# UI + code-behind 相近的开发模型，但语言和控件声明都保持中文。

## 运行项目与预览窗体

- `Ctrl+F5`：先运行 `.yyproj` 中声明的项目入口，再打开项目启动窗体。
- 打开项目：默认显示启动窗体设计器，而不是先显示入口文本。
- `F5` 或“预览窗体”：运行当前窗体并显示真实 Windows 原生窗口。
- `Ctrl+B` 或“编译 EXE”：把项目代码生成 C#，再编译为独立 Windows 可执行文件。
- 在预览中点击绑定按钮：编译并执行对应代码后置事件。
- 事件输出显示在预览窗口底部。

编译产物不依赖源码目录，也不包含可被运行时重新解析的 `.yyc/.yyx` 工程。技术细节见 [项目编译](compiler.md)。

## 当前边界

- 项目属性已可编辑，但暂未支持资源选择器、包引用可视化和多程序集。
- 已能把项目编译为独立 `.exe`；当前为自包含 IL/托管运行时二进制，纯机器码后端仍在路线图中。
- 已提供窗体的载入和关闭事件；尚未提供完整焦点、按键、尺寸变化、数据绑定与多窗体导航 API。
- 控件是按名称注入的全局对象，不是已完成的强类型窗体类；后续会由静态类型系统生成类型化控件成员。
- `.yyproj` 的“引用”目前用于文件依赖，包管理器尚未实现。
