# 项目结构与三文件工程

## 项目而非单文件

易语项目以 `.yyproj` 为根清单。入口、模块、窗体和用户代码各自保存，由项目清单和固定命名规则建立关系。

新建可视化项目会生成：

```text
DemoProject/
├─ DemoProject.yyproj
├─ Program.yyc
├─ Forms/
│  ├─ MainForm.yyx
│  ├─ MainForm.Designer.yyc
│  └─ MainForm.yyc
└─ Resources/
```

- `Program.yyc`：项目入口。
- `MainForm.yyx`：界面与视觉属性。
- `MainForm.Designer.yyc`：自动生成的事件关系，不手工编辑。
- `MainForm.yyc`：事件入口与用户业务逻辑。

纯代码工程可以只有 `.yyproj` 和 `.yyc` 文件，不要求任何窗体。

## `.yyproj` 格式版本 3

```json
{
  "格式版本": 3,
  "名称": "DemoProject",
  "入口": "Program.yyc",
  "输出": "DemoProject.exe",
  "启动窗体": "MainForm",
  "源码": [
    "Program.yyc",
    "Forms/MainForm.yyc"
  ],
  "窗体": [
    "Forms/MainForm.yyx"
  ],
  "资源": [],
  "引用": []
}
```

| 字段 | 说明 |
|---|---|
| `格式版本` | 必须为 `3` |
| `名称` | 项目名称 |
| `入口` | 启动源码，`Ctrl+F5` 运行 |
| `输出` | 默认 EXE 文件名 |
| `启动窗体` | 项目启动后打开的窗体名 |
| `源码` | 用户源码和模块，不能包含 `.Designer.yyc` |
| `窗体` | 界面 XML 列表 |
| `资源` | 图标、图片等资源相对路径 |
| `引用` | 项目依赖文件 |

所有路径必须位于项目目录内。版本 1、2 不再兼容；读取时会直接报告只支持版本 3。

## 窗体三件套校验

项目加载时，对每个 `Forms/MainForm.yyx` 自动检查：

1. `Forms/MainForm.Designer.yyc` 存在；
2. 关系文件根元素为 `窗体绑定`；
3. 界面与代码文件名和关系声明一致；
4. `Forms/MainForm.yyc` 存在；
5. 关系文件引用的控件在界面中真实存在且类型一致；
6. 用户代码文件出现在源码列表中。

任一检查失败都会阻止项目加载并指出缺失或冲突的文件。Studio 不会静默生成一个可能导致事件丢失的替代文件。

## 事件创建流程

在窗体设计器中双击按钮时：

1. 根据控件名与事件名计算处理程序名；
2. 在用户 `.yyc` 中创建事件子程序和可编辑注释；
3. 把事件映射写入内存窗体模型；
4. 重新生成 `.Designer.yyc`；
5. 切换到用户代码并定位到事件入口。

保存窗体时再次根据界面和事件状态重建关系文件，因此改名、删除控件或切换事件后不会留下陈旧映射。

## 运行、预览与编译

- `F5`：运行当前纯代码文件，或预览当前窗体。
- `Ctrl+F5`：运行项目入口后打开启动窗体。
- `Ctrl+Enter`：预览被设计窗口。
- `Ctrl+B`：编译项目为 Windows EXE。

预览和编译执行用户 `.yyc` 中的函数。自动关系文件负责把真实控件事件解析到这些函数，不作为第二个业务源码参与编译。

## 程序数据树

项目中的每个窗体展开后显示三层：

```text
主窗口
├─ 界面  主窗体.yyx
├─ 关系  主窗体.Designer.yyc
└─ 代码  主窗体.yyc
```

关系文件以只读文本形式打开并提示“自动生成”。用户代码和普通模块进入结构化代码编辑器。
