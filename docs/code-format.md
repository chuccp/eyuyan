# 结构化代码格式

## 为什么使用结构化 `.yyc`

纯文本源码适合编译，但 IDE 还需要稳定识别子程序边界、步骤类型、赋值目标、控件成员引用和调试定位。`.yyc` 因此使用 UTF-8 XML 保存语法模型，由编辑器投影成代码行和表格。

磁盘上的 XML 不是程序员的唯一工作界面：

- 易语言式代码窗口使用紧凑方法声明表加连续执行代码，也是默认视图；
- 纯代码模式可隐藏方法表和导航装饰，直接编辑完整源码；
- 两种视图共享补全、参数提示、自动配对和同一份结构化模型。

## 工程文件类型

| 文件 | 职责 |
|---|---|
| `.yyproj` | 项目清单格式版本 1 |
| `.yyx` | 一个界面的 XML 外观、布局和视觉属性 |
| `.Designer.yyc` | 与该界面同主名的自动生成事件关系 |
| `.yyc` | 与该界面同主名的用户代码；也可作为入口或普通模块 |
| `Resources/ids.xml` | 自动生成的窗体、控件和资源标识 |

每个可视化界面固定由以下三个文件组成，三者必须位于同一目录并使用相同主文件名：

```text
Sources/Forms/
├─ MainForm.yyx              界面 XML
├─ MainForm.Designer.yyc     自动生成关系
└─ MainForm.yyc              用户代码
```

`.yyproj` 是项目管理入口，`Resources/ids.xml` 是项目和资源关联索引，二者不属于界面的三个组成文件。完整职责和保存流程见 [界面架构](architecture.md)。

## `.yyx` 示例

`.yyx` 只保存界面。窗体和每个控件都带有稳定标识，但不得包含事件处理程序名、子程序或业务语句：

```xml
<?xml version="1.0" encoding="utf-8"?>
<yy:窗体 xmlns:yy="urn:yy-studio:form:1"
         标识="@id/主窗口"
         名称="主窗口"
         标题="客户登记"
         图标="@资源/图片/应用图标"
         宽="760"
         高="500"
         背景="#F4F7FB">
  <yy:文本 标识="@id/主窗口/标题标签"
          名称="标题标签"
          文本="客户信息"
          左="40" 上="32" 宽="240" 高="40" />
  <yy:按钮 标识="@id/主窗口/保存按钮"
          名称="保存按钮"
          文本="保存客户"
          左="184" 上="272" 宽="130" 高="42" />
</yy:窗体>
```

`.yyx` 与同名 `.Designer.yyc`、同名 `.yyc` 一起构成一个界面；缺少任何一个文件，项目加载器都会拒绝加载。

## `.yyc` 示例

```xml
<?xml version="1.0" encoding="utf-8"?>
<yy:代码 xmlns:yy="urn:yy-studio:code:1"
         格式版本="1"
         名称="主窗体代码">
  <yy:引入 路径="demo.app.工具" />
  <yy:子程序 名称="_保存按钮_被单击" 备注="保存按钮 · 单击">
    <yy:如果 条件="修剪(姓名输入框.文本) == &quot;&quot;">
      <yy:调用 值="提示(&quot;请先填写姓名&quot;)" />
      <yy:返回 />
    </yy:如果>
    <yy:赋值 目标="标题标签.文本"
             运算符="="
             值="&quot;欢迎，&quot; + 姓名输入框.文本" />
  </yy:子程序>
  <yy:入口>
    <yy:调用 值="输出(&quot;程序启动&quot;)" />
  </yy:入口>
</yy:代码>
```

表达式保留易语源码，例如 `姓名输入框.文本`、`长度(数组)` 和 `条件 且 条件`。XML 元素负责确定步骤类型，表达式负责具体运算。

## `.Designer.yyc` 示例

关系文件是纯文本易语代码，不是 XML：

```text
.版本 1
.程序集 主窗口.Designer
导入包 "系统.界面"

' 此文件由易语 Studio 自动生成，请勿手工修改。
界面("主窗口", "主窗体.yyx", "主窗体.yyc")

控件("@id/主窗口/标题标签", "标题标签", "文本")
控件("@id/主窗口/保存按钮", "保存按钮", "按钮")

绑定("@id/主窗口", "载入", "_主窗口_创建完毕")
绑定("@id/主窗口/保存按钮", "单击", "_保存按钮_被单击")
```

`界面()` 声明关系所属文件和代码文件，`控件()` 把可读名称映射到稳定资源 ID，`绑定()` 把事件连接到用户子程序。IDE 以只读代码方式显示，保存窗体时完全重建；该文件不能进入项目 `源码` 列表重复编译。

## 组件与代码关联

关系文件保存控件事件到处理程序的映射。用户代码保存同名子程序：

```xml
<yy:子程序 名称="_保存按钮_被单击">
  <yy:调用 值="提示(&quot;已保存&quot;)" />
</yy:子程序>
```

IDE 打开用户代码后生成只读关联索引：

- 每个控件显示类型和事件数；
- 每个事件显示是否已有同名子程序；
- 控件名可作为表达式标识符；
- 赋值面板可枚举真实控件属性；
- 关联索引不写回用户 `.yyc`。

事件映射只持久化一次，避免界面 XML 与关系文件各存一份导致漂移。

## 模块边界

- 项目入口、模块和用户代码使用 `.yyc`。
- 源码和窗体三件套必须位于 `Sources/`，资源必须位于 `Resources/`。
- 界面只能使用 `.yyx`。
- 关系只能使用同主名 `.Designer.yyc`。
- `.Designer.yyc` 不能出现在项目 `源码` 列表。
- `引入 "项目包名.子目录"` 会加载 `Sources/子目录/` 下的全部非生成 `.yyc`。
- 资源文件只能放在 `Resources/`，并与 `Resources/ids.xml` 中的标识对应。
- 当前结构化模型覆盖变量、常量、赋值、调用、条件、循环、遍历、尝试、返回、跳出和继续。
- 新增语法节点必须同步更新转换器、编辑器和测试，公开格式标识统一为 `1`。

## 损坏恢复

XML 损坏时显示行列号和明确消息。用户可在纯代码修复模式下编辑可读源码，修复后重新进入表格视图。合法文件默认进入结构化编辑。
