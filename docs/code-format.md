# 源代码与结构化模型

## `.yyc` 是纯源代码

`.yyc` 始终是 UTF-8 易语源代码。IDE 在打开文件时由解析器构建内存结构，用于识别子程序边界、步骤类型、赋值目标、控件成员引用和调试定位。

格式版本属于 `.yyproj` 和自动关系协议。老语法文件头 `.版本 2`、`.支持库` 作为声明行接受并登记(老易语言代码必须能跑);新源码由工程清单管理格式版本,不写 `.版本` 头。

源代码既是编译输入，也是用户直接编辑和版本控制的内容：

- “经典视图”使用紧凑方法声明表和连续执行代码，也是默认视图；
- 纯代码模式可隐藏方法表和导航装饰，直接编辑完整源码；
- 两种视图共享补全、参数提示、自动配对和同一份解析模型；
- 保存时写回源码，不生成 XML 或第二份重复代码。

## 工程文件类型

| 文件 | 职责 |
|---|---|
| `.yyproj` | 项目清单格式版本 1 |
| `.yyx` | 一个界面的 XML 外观、布局和视觉属性 |
| `.Designer.yyc` | 与该界面同主名的自动生成事件关系 |
| `.yyc` | 与该界面同主名的用户代码；也可作为入口或普通模块 |
| `Resources/ids.xml` | 自动生成的窗体、控件和资源标识 |

每个可视化界面固定由以下三个文件组成，三者必须位于同一目录并使用相同主文件名：

```text
Sources/Forms/
├─ MainForm.yyx              界面 XML
├─ MainForm.Designer.yyc     自动生成关系
└─ MainForm.yyc              用户代码
```

`.yyproj` 是项目管理入口，`Resources/ids.xml` 是项目和资源关联索引，二者不属于界面的三个组成文件。完整职责和保存流程见 [界面架构](architecture.md)。

## `.yyx` 示例

`.yyx` 只保存界面。窗体和每个控件都带有稳定标识，但不得包含事件处理程序名、子程序或业务语句：

```xml
<?xml version="1.0" encoding="utf-8"?>
<yy:窗体 xmlns:yy="urn:yy-studio:form:1"
         标识="@id/主窗口"
         名称="主窗口"
         标题="客户登记"
         图标="@资源/图片/应用图标"
         宽="760"
         高="500"
         背景="#F4F7FB">
  <yy:文本 标识="@id/主窗口/标题标签"
          名称="标题标签"
          文本="客户信息"
          左="40" 上="32" 宽="240" 高="40" />
  <yy:按钮 标识="@id/主窗口/保存按钮"
          名称="保存按钮"
          文本="保存客户"
          左="184" 上="272" 宽="130" 高="42" />
</yy:窗体>
```

`.yyx` 与同名 `.Designer.yyc`、同名 `.yyc` 一起构成一个界面；缺少任何一个文件，项目加载器都会拒绝加载。

## `.yyc` 示例

```text
.程序集 主窗体代码
导入包 "系统.基础"
导入包 "系统.文本"
导入包 "系统.界面"
引入 "demo.app.工具"

子程序 _保存按钮_被单击()
    如果 修剪(主窗体.姓名输入框.文本) == "" 则
        提示("请先填写姓名。")
        返回
    结束如果
    主窗体.标题标签.文本 = "欢迎，" + 主窗体.姓名输入框.文本
    主窗体.标题 = "客户登记 · 已保存"
结束子程序

输出("程序启动")
```

源码保持中文可读格式，例如 `主窗体.姓名输入框.文本`、`长度(数组)` 和 `条件 且 条件`。窗体名是根结构体，控件是其成员；IDE 可以通过解析器确定每一步的类型，但不会把代码改写成 XML。

## `.Designer.yyc` 示例

关系文件是纯文本易语代码，不是 XML：

```text
.程序集 主窗口.Designer
导入包 "系统.界面"

' 此文件由易语 Studio 自动生成，请勿手工修改。
结构体 主窗口文件
    界面: 文本 = "主窗体.yyx"
    代码: 文本 = "主窗体.yyc"
结束结构体

结构体 主窗口界面
    标题标签: 任意 = {标识: "@id/主窗口/标题标签", 类型: "文本"}
    保存按钮: 任意 = {标识: "@id/主窗口/保存按钮", 类型: "按钮"}
结束结构体

结构体 主窗口事件
    载入: 文本 = "_主窗口_创建完毕"
    保存按钮_单击: 文本 = "_保存按钮_被单击"
结束结构体
```

`窗体名文件` 声明界面与代码文件，`窗体名界面` 把控件成员映射到稳定资源 ID，`窗体名事件` 把窗体及控件事件连接到用户子程序。`@id/...` 只出现在生成关系中，用户代码使用 `主窗口.标题标签.文本` 和 `主窗口.标题`。IDE 以只读代码方式显示，保存窗体时完全重建；该文件不能进入项目 `源码` 列表重复编译。

## 组件与代码关联

关系文件保存控件事件到处理程序的映射。用户代码保存同名子程序：

```text
子程序 _保存按钮_被单击()
    提示("已保存")
结束子程序
```

IDE 打开用户代码后生成只读关联索引：

- 每个控件显示类型和事件数；
- 每个事件显示是否已有同名子程序；
- 窗体名可作为根结构体，控件名可作为其成员；
- 赋值面板可枚举真实控件属性；
- 关联索引不写回用户 `.yyc`。

事件映射只持久化一次，避免界面 XML 与关系文件各存一份导致漂移。

## 跨窗体代码

所有项目窗体共享同一套窗体结构体；窗体交互采用 VS/MFC 式拥有者、模态和结果模型。A 不直接修改 B 的控件：

```text
' A 窗体事件
子程序 _修改按钮_被单击()
    _修改窗口.参数 = _启动窗口.内容标签.文本
    如果 打开窗口("@id/_修改窗口", "@id/_启动窗口") 则
        _启动窗口.内容标签.文本 = _修改窗口.结果
    结束如果
结束子程序

' B 窗体每次显示前初始化草稿
子程序 _修改窗口_打开()
    _修改窗口.内容输入框.文本 = _修改窗口.参数
结束子程序

' B 窗体事件
子程序 _确认按钮_被单击()
    _修改窗口.结果 = _修改窗口.内容输入框.文本
    关闭窗口("@id/_修改窗口", 真)
结束子程序
```

`显示窗口(窗口, 拥有者)` 用于非模态窗口。系统关闭按钮和 `关闭窗口(窗口, 假)` 都把结果标记为取消。

完整工程位于 `examples/窗口交互/`。

## 模块边界

- 项目入口、模块和用户代码使用 `.yyc`。
- 源码和窗体三件套必须位于 `Sources/`，资源必须位于 `Resources/`。
- 界面只能使用 `.yyx`。
- 关系只能使用同主名 `.Designer.yyc`。
- `.Designer.yyc` 不能出现在项目 `源码` 列表。
- `引入 "项目包名.子目录"` 会加载 `Sources/子目录/` 下的全部非生成 `.yyc`。
- 资源文件只能放在 `Resources/`，并与 `Resources/ids.xml` 中的标识对应。
- 当前结构化模型覆盖变量、常量、赋值、调用、条件、循环、遍历、尝试、返回、跳出和继续。
- 新增语法节点必须同步更新转换器、编辑器和测试，公开格式标识统一为 `1`。

## 损坏恢复

`.yyx` XML 损坏时显示行列号和明确消息；`.yyc` 源代码解析失败时同样定位到具体行列。用户可在“纯代码”修复模式下编辑源码，修复后重新进入“经典视图”。
