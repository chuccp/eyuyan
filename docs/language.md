# 易语语言参考

## 结构体与接口

结构体用于定义稳定的数据结构，接口用于声明跨结构体契约。结构体通过对象字面量构造，字段顺序必须与声明一致：

```text
接口 可问候
    子程序 问候(): 文本
结束接口

结构体 学生 实现 可问候
    姓名: 文本
    年龄: 数字
结束结构体

变量 张三: 学生 = {姓名: "张三", 年龄: 18}
输出(张三.姓名)
```

当前结构体支持基础类型和数组字段；接口第一版用于类型和公开契约校验，运行时多态方法分派仍在后续实现。系统 SDK 的完整结构体、接口和方法声明位于 `sdk/Sources`。

## 程序结构

源码使用纯 UTF-8 文本 `.yyc`，由 IDE 解析成结构化模型后显示为方法表和连续代码行。格式版本由工程清单管理，`.yyc` 不写 `.版本` 头；`.程序集` 等源码声明保留在文件中。没有被子程序包裹的命令作为入口程序运行。

易语吸收 Python 的简洁表达式、函数调用、集合字面量和无分号风格，但使用中文块结束标记，降低初学者的记忆负担。同一 `.yyc` 可在默认“经典视图”和“纯代码”模式间切换，两种视图共享补全、参数提示、F1 帮助和自动配对。

除语言关键字、运算符和类型名外，命令必须来自已导入包。为突出语法，后续短示例省略导入声明；完整程序应按实际使用的命令添加 `导入包`。

```text
.程序集 示例

子程序 问候(姓名, 前缀 = "你好")
    返回 前缀 + "，" + 姓名
结束子程序

输出(问候("世界"))
```

## 注释

单行注释使用 `'`、`//` 或 `#`。

```text
' 这是注释
// 这也是注释
# 这也是注释
```

## 值与集合

- 数字：`1`、`2.5`
- 文本：`"你好"`、`“中文引号也可以”`
- 逻辑：`真`、`假`
- 空值：`空`
- 数组：`[1, 2, 3]`
- 对象：`{姓名: "林川", 年龄: 20}`

数组索引从 0 开始。对象属性和索引均可赋值。

```text
变量 用户 = {姓名: "林川", 标签: ["中文", "原生"]}
用户.姓名 = "新名字"
用户.标签[1] = "Windows"
输出(用户.标签[1])
```

## 变量与常量

```text
变量 名称 = "易语"
变量 年龄: 数字 = 20
常量 税率 = 0.13
名称 = "易语 Studio"
```

子程序中的变量属于本地作用域。条件、循环和尝试块会建立子作用域，能够读取并修改外层变量，但新变量不会泄漏到外层。

## 类型标注

变量、参数和返回值可以添加中文类型标注：

```text
子程序 格式化年龄(年龄: 数字): 文本
    返回 "年龄：" + 文本(年龄)
结束子程序

变量 年龄: 数字 = 20
变量 名字: 文本 = "林川"
变量 标签: 数组 = ["中文", "原生"]
变量 用户: 对象 = {姓名: 名字, 年龄: 年龄}
```

当前类型包括 `任意`、`数字`、`文本`、`逻辑`、`数组`、`对象`、`日期` 和 `空`。

- 标注会在声明、参数传入、每次赋值和返回时检查。
- 未标注的位置保持动态类型。
- `数字` 当前是双精度浮点值。
- 静态推断、结构化元素类型和可空类型仍属于后续工作。

## 运算符

| 类别 | 运算符 |
|---|---|
| 逻辑 | `且`、`&&`、`或`、`||`、`非`、`!` |
| 空值合并 | `??` |
| 比较 | `==`、`!=`、`等于`、`不等于`、`<`、`<=`、`>`、`>=` |
| 算术 | `+`、`-`、`*`、`/`、`%` |
| 复合赋值 | `+=`、`-=`、`*=`、`/=`、`%=` |

`+` 在任一侧为文本时执行文本拼接。逻辑 `且` 和 `或` 使用短路求值。

## 条件

```text
如果 分数 >= 90 则
    输出("优秀")
否则如果 分数 >= 60 则
    输出("及格")
否则
    输出("需要努力")
结束如果
```

## 循环

```text
计次循环 序号 从 1 到 10
    输出(序号)
结束循环

当 条件 循环
    跳出
结束循环

遍历 元素 于 [1, 2, 3]
    输出(元素)
结束遍历
```

`跳出` 结束当前循环，`继续` 进入下一轮。遍历对象时得到键名。

## 子程序

```text
子程序 求和(数字: 数组, 偏移: 数字 = 0): 数字
    变量 结果 = 偏移
    遍历 值 于 数字
        结果 += 值
    结束遍历
    返回 结果
结束子程序
```

允许递归，默认最大调用深度为 128 层。参数默认值在调用时求值。

## 系统 SDK 包

在程序集声明后使用 `导入包` 声明系统能力：

```text
.程序集 包示例

导入包 "系统.基础"
导入包 "系统.界面"

保存按钮.文本 = "已保存"
窗口.标题 = "客户管理 · 已保存"
```

控件名和窗口名由 `.Designer.yyc` 生成映射，用户源码不保存 `@id/...`。语言核心包为 `系统.基础`、`系统.集合`、`系统.文本`、`系统.数据`；平台 SDK 包为 `系统.界面`、`系统.文件`。包名会被解析、序列化和跨模块合并；未知包或使用未导入的函数都会在源码位置报告诊断。关键字、运算符和类型名由语言自身提供，其余函数必须来自已导入包。详见 [系统 SDK](sdk.md)。

## 跨文件模块

使用相对路径引入其他 `.yyc` 文件：

```text
引入 "工具.yyc"

输出(取欢迎语("易语开发者"))
```

被引用的文件可以定义子程序。当前模块函数位于共享全局命名空间，重复函数名会在编译阶段报错；循环引用会指出发生冲突的源码文件和行列位置。模块顶层初始化语句、命名空间和公开/私有访问控制尚未实现。

项目工程还可以按源码目录导入。假设工程包名为 `demo.app`，源码位于 `Sources/`：

```text
引入 "demo.app.工具"
```

这会加载 `Sources/工具/` 目录下的全部非生成 `.yyc` 文件，行为接近 Go 的目录包。点号对应目录层级，例如 `demo.app.数据.文本` 对应 `Sources/数据/文本/`。目录不存在、为空或超出 `Sources/` 时会给出包含预期路径的诊断；需要单个文件时仍可使用 `引入 "工具/文本.yyc"`。

## 项目清单

文件夹根目录可以放置一个 `.yyproj` 项目清单：

```json
{
  "格式版本": 1,
  "名称": "我的应用",
  "包名": "demo.app",
  "源码目录": "Sources",
  "资源目录": "Resources",
  "入口": "Sources/主程序.yyc",
  "输出": "我的应用.exe",
  "源码": ["Sources/主程序.yyc"],
  "窗体": [],
  "资源": [],
  "资源标识": "Resources/ids.xml",
  "引用": []
}
```

IDE 打开项目目录后会读取名称，并自动打开清单中的入口文件。`F5` 编译并运行当前工程，同时展开底部控制台；没有工程时运行当前标签页。`Ctrl+F5` 始终运行项目入口。

## 异常保护

```text
尝试
    变量 结果 = 10 / 0
捕获 错误
    输出("发生错误：" + 错误)
结束尝试
```

当前会捕获运行时错误；用户主动停止程序不会被 `捕获` 吞掉。

## 内置函数

| 函数 | 说明 |
|---|---|
| `输出(值…)` | 打印到 IDE 运行输出 |
| `取控件("@id/窗体/控件")` | 底层动态 ID 访问；普通界面代码直接使用生成的控件名和窗口名 |
| `提示(值…)` | 打印带提示标记的输出 |
| `长度(集合)` | 文本、数组或对象长度 |
| `类型(值)` | 类型名 |
| `数字(值)`、`整数(值)`、`小数(值, 位数)` | 数字转换 |
| `文本(值)` | 转为文本 |
| `范围(开始, 结束[, 步长])` | 左闭右开数字数组 |
| `包含`、`分割`、`连接`、`替换`、`修剪` | 文本操作 |
| `追加`、`插入`、`移除`、`排序`、`倒序` | 数组操作 |
| `键集`、`值集` | 对象键与值 |
| `JSON解析`、`JSON生成` | JSON 互转 |
| `当前时间`、`格式化时间` | 日期时间 |
| `UTF8编码`、`UTF8解码` | UTF-8 与 Base64 互转 |
| `断言(条件[, 提示])` | 断言条件 |
