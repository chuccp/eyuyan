# 易语语言参考

易语完整支持**老语法**(官方易语言语汇):声明行、点前缀语句、收口行、全角运算符、
省略参数与 `#常量`,老易语言代码必须能跑。**新语汇**(强类型内联声明、缩进块、
`返回 ()` 等)是老语法的超集,两者可在同一文件混用。
黄金对照样本见 [docs/reference/老语法基准-中华办公系统.e.txt](reference/老语法基准-中华办公系统.e.txt)。

## 程序结构

源码使用纯 UTF-8 文本 `.yyc`,由 IDE 解析成结构化模型后显示为方法表和连续代码行。
没有被子程序包裹的命令作为入口程序运行;老语法程序没有顶层语句时,
以事件子程序 `__启动窗口_创建完毕` 为入口执行。

## 老语法(官方语汇)

### 文件头与声明行

老语法文件以点前缀声明行组织;`.版本`/`.支持库` 为文件头:

```text
.版本 2
.支持库 系统核心支持库

.程序集 启动窗口程序集
.程序集变量 运行目录, 文本型
.程序集变量 目录, 文本型, , "0"
.常量 步长, 整数型, 2

.子程序 __启动窗口_创建完毕
.局部变量 计次, 整数型
.局部变量 命令行, 文本型

.子程序 格式化年龄, 文本型
.参数 年龄, 整数型
.局部变量 结果, 文本型
```

- `.程序集变量 名, 类型[, 备注[, "0"]]`:程序集(全局)变量;`"0"` 标记数组。
- `.常量 名, 类型, 值`:常量;引用带 `#` 前缀(`#步长`)。
- `.子程序 名[, 返回值类型[, 备注[, *]]]`:子程序声明行;`*` 为公开标记。
- `.参数 名, 类型[, 备注[, "0"]]`、`.局部变量 …`:声明行内的参数与局部变量。
- 官方类型名(`整数型`/`文本型`/`逻辑型`/`字节集`…)按别名接受(见“类型”)。
- 子程序语句体到下一个声明行或文件尾结束。

### 语句(点前缀 + 收口行)

老语法语句可带 `.` 前缀,块以收口行结束,不依赖缩进:

```text
.如果真 (条件)
    语句
.如果真结束

.如果 (条件)
    语句
.否则
    语句
.如果结束

.判断开始 (条件)
    语句
.判断 (条件)
    语句
.默认
    语句
.判断结束
```

### 循环(五种官方形态)

```text
.计次循环首 (循环次数, 计次变量)   ' 计次从 1 到次数
    语句
.计次循环尾 ()

.变量循环首 (变量, 起始, 结束[, 步长])
    语句
.变量循环尾 ()

.判断循环首 (条件)               ' 先判断后执行
    语句
.判断循环尾 ()

.循环判断首 ()                   ' 先执行后判断
    语句
.循环判断尾 (条件)

.遍历循环首 (变量, 集合)
    语句
.遍历循环尾 ()
```

`跳出循环 ()` 结束当前循环,`继续循环 ()` 进入下一轮。

### 表达式写法

- 全角运算符与官方一致:`＝ ＋ － × ÷ ＞ ＜ ≥ ≤ ≠`,与半角写法等价;条件中 `=`/`＝` 表示相等比较。
- 省略参数:`载入 (欢迎窗口, , 假)`、`信息框 (“提示”, #信息图标, )`;省略位置取声明默认值。
- `#常量`、`#常量组.成员` 为常量引用;`&子程序名` 取子程序地址。
- `返回 ()` 无返回值,`返回 (表达式)` 带值。
- 注释行以 `'` 开头。

## 易语新语汇(超集)

### 强类型内联声明

变量、常量、参数声明必须带类型,与声明行等价:

```text
变量 名称: 文本 = "易语"
变量 年龄: 数字 = 20
常量 税率: 数字 = 0.13
```

子程序内联声明:

```text
子程序 问候(姓名: 文本, 前缀: 文本 = "你好"): 文本
    返回 (前缀 + "，" + 姓名)
结束子程序
```

`结束子程序`、`结束结构体`、`结束接口` 为声明收口(格式保留);语句块不写收口行。

### 缩进块与简明语汇

语句块可按缩进界定(对齐 Python),收口行可省略;分支/循环使用简明关键字:

```text
如果真 (分数 >= 90)
    输出("优秀")

判断开始 (分数 >= 90)
    输出("优秀")
判断 (分数 >= 60)
    输出("及格")
默认
    输出("需要努力")

当 条件 循环
    跳出

计次循环 序号 从 1 到 10
    输出(序号)

遍历 元素 于 [1, 2, 3]
    输出(元素)
```

文本风格的 `如果 条件 则 / 否则如果 / 否则 / 结束如果` 同样支持;保存时统一输出为新语汇。

## 结构体与接口

```text
接口 可问候
    子程序 问候(): 文本
结束接口

结构体 学生 实现 可问候
    姓名: 文本
    年龄: 数字
结束结构体

变量 张三: 学生 = {姓名: "张三", 年龄: 18}
输出(张三.姓名)
```

## 类型

规范类型名:`任意`、`数字`、`文本`、`逻辑`、`数组`、`对象`、`日期`。官方类型名作为别名接受,自动归一:

| 官方类型名 | 归一为 |
|---|---|
| `整数型`、`短整数型`、`长整数型`、`小数型`、`双精度小数型`、`字节型` | `数字` |
| `文本型` | `文本` |
| `逻辑型` | `逻辑` |
| `字节集` | `任意` |
| `日期时间型` | `日期` |
| `数组型` | `数组` |
| `对象型` | `对象` |

未知类型名按自定义类型接受(老语法支持库类型如“字体”“页面接口”)。类型在声明、传参、赋值和返回时检查。

## 值与集合

- 数字:`1`、`2.5`;文本:`"你好"`、`“中文引号也可以”`;逻辑:`真`、`假`;空值:`空`
- 数组:`[1, 2, 3]`;对象:`{姓名: "林川", 年龄: 20}`
- 注释:`'`、`//`、`#`(行注释;`#` 后接标识符字符时是常量名)

## 运算符

| 类别 | 运算符 |
|---|---|
| 逻辑 | `且`、`&&`、`或`、`||`、`非`、`!` |
| 空值合并 | `??` |
| 比较 | `==`、`!=`、`等于`、`不等于`、`<`、`<=`、`>`、`>=`(全角 `＞＜≥≤≠` 等价) |
| 算术 | `+`、`-`、`*`、`/`、`%`(全角 `＋－×÷％` 等价) |
| 复合赋值 | `+=`、`-=`、`*=`、`/=`、`%=` |

条件表达式中 `=`、`＝` 按相等处理。`+` 在任一侧为文本时执行拼接;`且`/`或` 短路求值。

## 异常保护

```text
尝试
    变量 结果: 数字 = 10 / 0
捕获 错误
    输出("发生错误：" + 错误)
```

老语法以 `.尝试 / .捕获 / .结束尝试` 收口,新语汇按缩进结束。

## 系统 SDK 包

程序集声明后使用 `导入包` 声明系统能力;内置函数签名使用强类型标注(如 `取文本左边(文本: 文本, 字符数: 数字): 文本`)。详见 [系统 SDK](sdk.md)。

```text
.程序集 包示例

导入包 "系统.基础"
导入包 "系统.界面"

_启动窗口.保存按钮.文本 = "已保存"
```

## 跨文件模块

```text
引入 "工具.yyc"
引入 "demo.app.工具"
```

被引用文件可定义子程序;重复函数名在编译阶段报错。目录包加载 `Sources/` 下全部非生成 `.yyc`。

## 项目清单

`.yyproj` 管理格式版本、包名、源码/资源目录、入口与引用;`F5` 编译并运行当前工程。老程序导入后即为标准工程。

## 内置函数

| 函数 | 说明 |
|---|---|
| `输出(值…)` | 打印到 IDE 运行输出 |
| `取控件("@id/窗体/控件")` | 底层动态 ID 访问;界面代码使用 `窗体名.控件名` |
| `打开窗口`、`显示窗口`、`关闭窗口` | 窗口会话(模态/非模态/结果) |
| `长度`、`类型`、`数字`、`整数`、`小数`、`文本` | 基础转换 |
| `范围`、`包含`、`分割`、`连接`、`替换`、`修剪` | 文本/数组操作 |
| `追加`、`插入`、`移除`、`排序`、`倒序`、`键集`、`值集` | 集合操作 |
| `JSON解析`、`JSON生成`、`当前时间`、`格式化时间` | 数据与时间 |
| `UTF8编码`、`UTF8解码`、`断言` | 工具 |

## 老程序转换

`yy convert <老程序.e> [--out 目录] [--name 项目名] [--package 包名]` 把老易语言程序
(CNWTEPRG `.e`)转换为易语工程;Studio“程序 → 导入老程序(.e)…”走同一流程:
选中 .e 后弹窗填写新目录(仿新建工程),再调用 `yy convert`。
转换按 `.e` 帧类型码解译子程序/程序集/变量/文本记录,产物保证可解析;
导入报告列出未归类文本供人工核对。语句表达式级还原仍在增强(见 [路线图](roadmap.md))。
