# 易语 3 语言参考

## 程序结构

源码使用 UTF-8 编码，文件扩展名为 `.ey`。`.版本`、`.程序集` 等点号指令用于工程元数据；没有被子程序包裹的语句作为入口程序运行。

```text
.版本 3
.程序集 示例

子程序 问候(姓名, 前缀 = "你好")
    返回 前缀 + "，" + 姓名
结束子程序

输出(问候("世界"))
```

## 注释

单行注释使用 `'`、`//` 或 `#`。

```text
' 这是注释
// 这也是注释
# 这也是注释
```

## 值与集合

- 数字：`1`、`2.5`
- 文本：`"你好"`、`“中文引号也可以”`
- 逻辑：`真`、`假`
- 空值：`空`
- 数组：`[1, 2, 3]`
- 对象：`{姓名: "林川", 年龄: 20}`

数组索引从 0 开始。对象属性和索引均可赋值。

```text
变量 用户 = {姓名: "林川", 标签: ["中文", "原生"]}
用户.姓名 = "新名字"
用户.标签[1] = "Windows"
输出(用户.标签[1])
```

## 变量与常量

```text
变量 名称 = "易语"
变量 年龄: 数字 = 20
常量 税率 = 0.13
名称 = "易语 Studio"
```

子程序中的变量属于本地作用域。条件、循环和尝试块会建立子作用域，能够读取并修改外层变量，但新变量不会泄漏到外层。

## 类型标注

变量、参数和返回值可以添加中文类型标注：

```text
子程序 格式化年龄(年龄: 数字): 文本
    返回 "年龄：" + 文本(年龄)
结束子程序

变量 年龄: 数字 = 20
变量 名字: 文本 = "林川"
变量 标签: 数组 = ["中文", "原生"]
变量 用户: 对象 = {姓名: 名字, 年龄: 年龄}
```

当前类型包括 `任意`、`数字`、`文本`、`逻辑`、`数组`、`对象`、`日期` 和 `空`。

- 标注会在声明、参数传入、每次赋值和返回时检查。
- 未标注的位置保持动态类型。
- `数字` 当前是双精度浮点值。
- 静态推断、结构化元素类型和可空类型仍属于后续工作。

## 运算符

| 类别 | 运算符 |
|---|---|
| 逻辑 | `且`、`&&`、`或`、`||`、`非`、`!` |
| 空值合并 | `??` |
| 比较 | `==`、`!=`、`等于`、`不等于`、`<`、`<=`、`>`、`>=` |
| 算术 | `+`、`-`、`*`、`/`、`%` |
| 复合赋值 | `+=`、`-=`、`*=`、`/=`、`%=` |

`+` 在任一侧为文本时执行文本拼接。逻辑 `且` 和 `或` 使用短路求值。

## 条件

```text
如果 分数 >= 90 则
    输出("优秀")
否则如果 分数 >= 60 则
    输出("及格")
否则
    输出("需要努力")
结束如果
```

## 循环

```text
计次循环 序号 从 1 到 10
    输出(序号)
结束循环

当 条件 循环
    跳出
结束循环

遍历 元素 于 [1, 2, 3]
    输出(元素)
结束遍历
```

`跳出` 结束当前循环，`继续` 进入下一轮。遍历对象时得到键名。

## 子程序

```text
子程序 求和(数字: 数组, 偏移: 数字 = 0): 数字
    变量 结果 = 偏移
    遍历 值 于 数字
        结果 += 值
    结束遍历
    返回 结果
结束子程序
```

允许递归，默认最大调用深度为 128 层。参数默认值在调用时求值。

## 跨文件模块

使用相对路径引入其他 `.ey` 文件：

```text
引入 "工具.ey"

输出(取欢迎语("易语开发者"))
```

被引用的文件可以定义子程序。当前模块函数位于共享全局命名空间，重复函数名会在编译阶段报错；循环引用会指出发生冲突的源码文件和行列位置。模块顶层初始化语句、命名空间和公开/私有访问控制尚未实现。

## 项目清单

文件夹根目录可以放置一个 `.yyproj` 项目清单：

```json
{
  "格式版本": 1,
  "名称": "我的应用",
  "入口": "主程序.ey",
  "输出": "我的应用.exe",
  "资源": [],
  "引用": []
}
```

IDE 打开项目目录后会读取名称，并自动打开清单中的入口文件。`Ctrl+F5` 始终运行项目入口，`F5` 运行当前标签页。

## 异常保护

```text
尝试
    变量 结果 = 10 / 0
捕获 错误
    输出("发生错误：" + 错误)
结束尝试
```

当前会捕获运行时错误；用户主动停止程序不会被 `捕获` 吞掉。

## 内置函数

| 函数 | 说明 |
|---|---|
| `输出(值…)` | 打印到 IDE 运行输出 |
| `提示(值…)` | 打印带提示标记的输出 |
| `长度(集合)` | 文本、数组或对象长度 |
| `类型(值)` | 类型名 |
| `数字(值)`、`整数(值)`、`小数(值, 位数)` | 数字转换 |
| `文本(值)` | 转为文本 |
| `范围(开始, 结束[, 步长])` | 左闭右开数字数组 |
| `包含`、`分割`、`连接`、`替换`、`修剪` | 文本操作 |
| `追加`、`插入`、`移除`、`排序`、`倒序` | 数组操作 |
| `键集`、`值集` | 对象键与值 |
| `JSON解析`、`JSON生成` | JSON 互转 |
| `当前时间`、`格式化时间` | 日期时间 |
| `UTF8编码`、`UTF8解码` | UTF-8 与 Base64 互转 |
| `断言(条件[, 提示])` | 断言条件 |
