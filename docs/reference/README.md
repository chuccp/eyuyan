# 参考资料

本目录是老语法(官方易语言语汇)与老程序转换的参考资料。

| 内容 | 说明 |
|---|---|
| `老语法基准-中华办公系统.e.txt` | 官方易语言完整源码(黄金对照):声明行、点前缀语句/收口行、五种循环、全角运算符、省略参数、`#常量` |
| `eyuyan-zlsc/`(本地,不入库) | 官方易语言教程下载目录(语言基础、运算符、控件、数据库等,day1-9 实例含 `.e` 样本);体积大,仅本地保留 |
| `tests/Yy.Studio.Core.Tests/fixtures/day1.e` | 入库的官方 `.e` 小样本(CNWTEPRG 二进制,`yy convert` 回归夹具) |

`.e` 二进制格式要点(转换器解译依据):

- 文件头魔数 `CNWTEPRG`;正文是带类型码的记录流,字符串帧为 `[int32 长度][GBK 文本]`。
- 帧前类型码:`01 19` 子程序名、`01 52` 程序集名、`01 03` 变量/参数行、`1a` 文本串(标题/属性值/语句文本/备注)。
- 语句表达式按操作码/命令 ID 序列化,完整还原仍在进行(路线图 LEGACY-04)。

更多官方样本位于安装目录 `C:\Program Files (x86)\e\samples`(25 类、145 个 `.e`)。
