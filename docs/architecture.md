# 三文件界面架构

易语 Studio 采用“界面、生成关系、用户代码”分离的桌面程序模型。设计目标与 Visual Basic、WinForms 的 `.Designer.cs` 思路接近，同时保持易语言式的组件箱、属性夹、事件入口和中文代码体验。

## 文件职责

```text
Forms/
├─ 主窗体.yyx              界面 XML：外观、布局、控件属性
├─ 主窗体.Designer.yyc     自动关系：控件事件 → 用户子程序
└─ 主窗体.yyc              用户代码：事件入口与自定义逻辑
```

三个文件位于同一目录，主文件名相同。工程只接受这一命名规则。

## 资源标识

工程的 `Resources/ids.xml` 是自动生成的关联索引，职责类似 Android 的资源 ID 表：

```text
Resources/
├─ ids.xml
├─ images/
├─ sounds/
└─ files/
```

界面 XML 使用稳定标识关联窗体和控件：

```xml
<yy:窗体 标识="@id/主窗口" 名称="主窗口">
  <yy:按钮 标识="@id/主窗口/保存按钮" 名称="保存按钮" />
</yy:窗体>
```

`ids.xml` 同时登记图片、声音和其他文件资源，例如 `@资源/图片/客户图标`。工程清单通过 `"资源标识": "Resources/ids.xml"` 声明索引位置。新建、保存窗体和保存资源表时自动重建；用户不需要手工编辑，也不能把它当作业务代码运行。

窗体的 `图标` 和图片框的 `图片` 属性可以直接保存资源标识。Studio 预览会从工程资源目录解析图标，生成 EXE 时则把图标数据嵌入程序，不依赖原工程目录。

### `主窗体.yyx`

界面文件使用 UTF-8 XML。它只描述用户看见的内容：

```xml
<yy:窗体 xmlns:yy="urn:yy-studio:form:1"
         标识="@id/主窗口" 名称="主窗口" 标题="客户登记" 宽="760" 高="500">
  <yy:按钮 标识="@id/主窗口/保存按钮" 名称="保存按钮" 文本="保存客户"
          左="184" 上="272" 宽="130" 高="42" />
</yy:窗体>
```

它不能包含 `单击`、`文本改变`、`载入`、`关闭`、`代码` 等逻辑关系。事件写入界面 XML 会被加载器拒绝并给出明确诊断。

### `主窗体.Designer.yyc`

关系文件由 Studio 完全生成，保存事件映射：

```xml
<yy:窗体绑定 xmlns:yy="urn:yy-studio:form-binding:1"
             格式版本="1" 窗体="主窗口"
             界面="主窗体.yyx" 代码="主窗体.yyc">
  <yy:窗体事件 类型="载入" 处理程序="_主窗口_创建完毕" />
  <yy:控件 名称="保存按钮" 类型="按钮">
    <yy:事件 类型="单击" 处理程序="_保存按钮_被单击" />
  </yy:控件>
</yy:窗体绑定>
```

该文件：

- 在 IDE 中只读；
- 每次保存界面时整体重建；
- 引用的控件必须存在于界面，控件类型必须一致；
- 不能当作普通用户模块编译；
- 不能被项目 `源码` 列表重复引用。

### `主窗体.yyc`

用户代码只保存可编辑的易语程序集、子程序、参数和逻辑。设计器在事件第一次建立时可以生成空事件入口，之后不会覆盖其内容：

```xml
<yy:代码 xmlns:yy="urn:yy-studio:code:1" 格式版本="1" 名称="主窗口代码">
  <yy:子程序 名称="_保存按钮_被单击" 备注="保存按钮 · 单击">
    <yy:调用 值="' 在这里编写“保存按钮 · 单击”的用户逻辑。" />
  </yy:子程序>
</yy:代码>
```

删除事件映射不会自动删除用户函数，避免误删业务代码。用户可以继续在别处调用该子程序，也可以自行清理。

## 保存流程

保存窗体时按以下顺序完成：

1. 校验界面模型。
2. 补齐用户文件中缺失的事件入口，保留已有函数和语句。
3. 写入 `.yyx`。
4. 从界面与事件映射重新生成 `.Designer.yyc`。
5. 重新载入项目索引并刷新程序数据树。

关系文件写入先使用同目录临时文件，再原子替换目标文件。生成失败不会破坏上一版关系文件。

## 两种编程方式

### 可视化优先

1. 从组件箱放置控件。
2. 用属性夹调整名称、标题、位置和样式。
3. 双击控件或从事件列表选择事件。
4. 在 `.yyc` 中填写事件逻辑。
5. 按 F5 预览，事件映射由生成层自动完成。

### 纯代码优先

无界面程序、算法库、控制台程序和模块直接使用 `.yyc`。项目入口也可以是纯代码文件，不需要创建任何窗体。

结构化 `.yyc` 使用旧版易语言式代码窗口：方法声明小表位于连续执行代码上方，并可切换到纯代码模式。保存时写回结构化文件，不产生第二份与用户代码竞争的源码。

## 工程格式

工程清单使用当前格式版本 `1`。界面、关联文件和资源标识必须符合本文结构；不符合时直接报错。
