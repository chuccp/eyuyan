# Studio 配置

易语 Studio 使用 UTF-8 JSON 配置文件 `YyStudio.json`。工程格式和配置格式版本均为 `1`。

## 配置文件位置

查找顺序如下：

1. 命令行 `--config <路径>` 指定的文件。
2. `%APPDATA%\YyStudio\YyStudio.json` 用户配置。
3. Studio 可执行文件同目录的 `YyStudio.json` 便携配置。
4. 以上均不存在时，在用户配置目录生成默认文件。

配置文件可通过“工具 → 打开 Studio 配置文件”直接打开。仓库根目录的
[`YyStudio.example.json`](../YyStudio.example.json) 可作为完整模板。

## 配置示例

```json
{
  "格式版本": 1,
  "MCP": {
    "启用": true,
    "端口": 37213,
    "自动寻找可用端口": true,
    "端口尝试次数": 10
  },
  "编辑器": {
    "字号": 13,
    "制表宽度": 4
  },
  "窗体设计器": {
    "吸附网格": true
  },
  "窗口布局": {
    "预设": "默认",
    "显示状态栏": true,
    "项目": { "停靠": "左侧", "状态": "显示", "尺寸": 260 },
    "程序与属性": { "停靠": "右侧", "状态": "显示", "尺寸": 360 },
    "控制台": { "停靠": "底部", "状态": "显示", "尺寸": 172 },
    "右侧活动页": 0
  },
  "启动": {
    "显示新建程序对话框": true
  },
  "快捷键": {
    "运行": ["F5"],
    "代码补全": ["Ctrl+Space"],
    "切换注释": ["Ctrl+/"]
  }
}
```

未写出的快捷键会使用默认值；将某个动作设为空数组可停用该快捷键。

语言语法、系统 SDK 包和内置命令不再作为可停用支持库配置，统一从
“帮助 → 易语开发文档”查看和搜索。

## 窗口布局

顶栏“布局”、查看菜单和窗口菜单都可调整工具窗口：

- `停靠`：`左侧`、`右侧`或`底部`。移动到已占用区域时与原有工具窗交换。
- `状态`：`显示`、`最小化`或`隐藏`。最小化保留侧边/底边恢复栏，隐藏后可从布局菜单恢复。
- `尺寸`：侧边工具窗表示宽度 180–760，底部工具窗表示高度 96–600。
- `预设`：`默认`、`专注代码`、`窗体设计` 或 `自定义`。
- `右侧活动页`：`0` 为程序，`1` 为属性。

项目、程序/属性、控制台的停靠区不能重复。拖动分隔线和窗口内操作会自动保存为“自定义”布局。

## MCP

- `启用`：是否启动 MCP 服务。
- `端口`：首选 HTTP 端口，范围为 1024–65535。
- `自动寻找可用端口`：端口被占用时是否顺延。
- `端口尝试次数`：自动查找时最多尝试的数量，范围为 1–100。

实际端口写入 `%TEMP%\yystudio-mcp.port`。修改 MCP 配置后需要重启 Studio。
连接示例：

```powershell
YyStudio.exe --mcp-port 38400
```

该命令行参数只覆盖本次启动的端口。端口变化后，引用固定
`http://127.0.0.1:37213/mcp` 的客户端配置也需要同步调整。

## 快捷键

快捷键使用 WPF `KeyGesture` 文本格式，例如：

```text
F5
Ctrl+S
Ctrl+Shift+S
Alt+F4
Ctrl+/
```

每个动作可以配置多个快捷键：

```json
"编译": ["Ctrl+B", "F7"]
```

可用动作及默认快捷键：

| 动作 | 默认值 |
|---|---|
| 新建源码 | `Ctrl+N` |
| 新建项目 | `Ctrl+Alt+N` |
| 新建窗体 | `Ctrl+Shift+N` |
| 打开文件 | `Ctrl+O` |
| 打开文件夹 | `Ctrl+Shift+O` |
| 保存 | `Ctrl+S` |
| 另存为 | `Ctrl+Shift+S` |
| 关闭标签 | `Ctrl+W` |
| 编译 | `Ctrl+B`、`F7` |
| 运行 | `F5` |
| 运行项目 | `Ctrl+F5` |
| 停止运行 | `Shift+F5` |
| 调试单步 | `F8` |
| 调试跳过 | `F10` |
| 调试跳出 | `Shift+F8` |
| 运行到光标 | `F4` |
| 切换断点 | `F9` |
| 代码补全 | `Ctrl+Space` |
| 上下文帮助 | `F1` |
| 格式化代码 | `Ctrl+Alt+L` |
| 切换注释 | `Ctrl+/` |
| 复制当前行 | `Ctrl+D` |
| 删除当前行 | `Ctrl+Shift+K` |

`运行`（`F5`）会编译并运行当前工程，底部控制台自动展开；没有工程时运行当前源码。`运行项目`（`Ctrl+F5`）始终按项目入口和启动窗体运行。设计器预览使用 `Ctrl+Enter`，不会编译 EXE。

工具窗口快捷键：`Alt+1` 项目、`Alt+2` 程序、`Alt+3` 属性、`Alt+4` 控制台、`Alt+5` 窗口组件箱。

配置保存时会检查：

- 动作名称必须存在于快捷键目录。
- 按键和修饰键必须可解析。
- 同一快捷键不能分配给多个动作。
- 空数组表示停用该动作。

## 设置窗口

“工具 → 系统配置”打开 JetBrains 风格设置窗口，左侧按编辑器、窗体、
MCP、快捷键和配置文件分组。点击“应用”立即保存，点击“确定”保存并关闭。
MCP 端口修改后需要重启 Studio；快捷键和编辑器外观会在应用后立即刷新。
