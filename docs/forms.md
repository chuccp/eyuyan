# 窗体设计器与 `.yyx` 格式

## 使用方式

1. 点击“程序→新建→新建窗口”，或按 `Ctrl+Shift+N`。
2. 从右侧“窗口组件箱”单击组件后拖到窗体上画出(组件命名按官方:标签N/按钮N/编辑框N/组合框N…);双击组件箱图标可直接放置。
3. 单击控件后拖动位置,拖动八个黑色方块手柄调整尺寸;左“属性”夹顶部下拉框可在窗口与各控件间切换。
4. 在左“属性”夹编辑官方属性名:名称/备注/左边/顶边/宽度/高度/可视/禁止(真/假)/标题/字号/前景/背景/选中;选中属性行在底部“提示”夹显示官方属性说明。
5. 按 `Delete` 删除所选控件,方向键微移 1 像素,`Shift+方向键` 微移 10 像素;`Ctrl+Z`/`Ctrl+Y` 或标准工具条撤销、重做。
6. 按 `Ctrl+S` 保存为 `.yyx`;`Ctrl+Enter` 或“查看→预览被设计窗口”打开原生窗口预览。
7. 双击控件按官方方式绑定默认事件(按钮→被单击,编辑框→内容被改变,复选框/单选框→选中状态被改变,组合框/列表框→列表项被选择),事件子程序命名为 `_控件名_事件名`,并切换到表格化代码编辑器;也可在“属性”夹底部“在此处选择加入事件处理子程序”下拉框中选择任意事件。
8. 在窗体上单击右键可打开“查看代码/预览窗体/菜单编辑器/删除所选控件”。

设计画布默认吸附 8 像素网格(对齐条末端“吸附网格”可关闭)。窗体在设计中心以官方样式呈现:蓝色标题栏、点阵网格客户区、中灰工作区。

## 文件结构

`.yyx` 使用 UTF-8 XML，根元素为 `窗体`，控件作为一层子元素保存。坐标原点是窗体左上角，单位是 DIP。

```xml
<?xml version="1.0" encoding="utf-8"?>
<窗体 xmlns="urn:yy-studio:form:1"
      名称="主窗口"
      代码="主窗体.yyc"
      载入="主窗口_载入"
      关闭="主窗口_关闭"
      标题="客户登记"
      宽="760"
      高="500"
      背景="#F4F7FB">
  <文本 名称="标题标签"
        文本="客户信息"
        左="40"
        上="32"
        宽="240"
        高="40"
        字号="24"
        前景="#17212B"
        背景="Transparent" />
  <按钮 名称="保存按钮"
        文本="保存客户"
        左="126"
        上="258"
        宽="130"
        高="42"
        字号="14"
        前景="#FFFFFF"
        背景="#2F7F6E"
        单击="保存按钮_被单击" />
</窗体>
```

## 字段

窗体属性：

| 属性 | 必需 | 说明 |
|---|---|---|
| `名称` | 是 | 窗体模型名称 |
| `标题` | 否 | 预览窗口标题，默认“易语窗体” |
| `宽` | 否 | 320 到 3840 |
| `高` | 否 | 240 到 2160 |
| `背景` | 否 | 颜色文本，例如 `#F4F7FB`、`Transparent` |

控件通用属性：

| 属性 | 说明 |
|---|---|
| `名称` | 控件唯一标识，同一窗体中不可重复 |
| `文本` | 标题、内容或列表初值 |
| `左`、`上` | 相对画布左上角的坐标 |
| `宽`、`高` | 控件尺寸 |
| `字号` | 6 到 96 |
| `前景`、`背景` | 颜色文本 |
| `启用` | `True` 或 `False` |
| `可见` | 设计时显示状态；`False` 在预览中隐藏 |
| `单击` | 事件处理函数名，在预览时执行代码后置事件 |
| `文本改变` | 输入框文本变化事件函数 |
| `选择改变` | 下拉框或列表框选择变化事件函数 |
| `选中改变` | 复选框选中状态变化事件函数 |
| `选中` | 复选框默认选中状态 |

窗体根元素还可声明：

| 属性 | 说明 |
|---|---|
| `代码` | 相对窗体目录的结构化代码后置文件 |
| `载入` | 窗体加载后执行的代码后置函数 |
| `关闭` | 窗体关闭前执行的代码后置函数 |

当前控件类型：`按钮`、`文本`、`输入框`、`复选框`、`下拉框`、`列表框`、`分组框`。

`下拉框` 和 `列表框` 的 `文本` 使用逗号分隔初始选项。

## 校验

- 根元素必须是 `窗体`。
- 每个控件必须有非空 `名称`，且同一窗体中不能重复。
- 不认识的控件元素会阻止加载，避免静默丢失界面。
- 数字、坐标范围和布尔值会校验。
- XML 错误、未知控件和重复名称会显示行列号；编辑器会回到 XML 文本模式以便修复。

## 当前边界

当前设计器采用固定坐标布局，支持基础控件、移动、缩放和常用属性。以下仍在路线图中：

- 嵌套容器和布局约束。
- 多选控件、对齐、分布和参考线。
- 双击事件自动跳转或生成 `.yyc` 处理函数。
- 强类型控件成员、数据绑定、资源与图片。
- 控件模板、主题和打包器集成。
