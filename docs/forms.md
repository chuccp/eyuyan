# 窗体设计器与界面 XML

## 三文件界面

可视化界面固定由三个文件组成：

```text
Sources/Forms/MainForm.yyx              界面 XML
Sources/Forms/MainForm.Designer.yyc     自动生成的事件关系
Sources/Forms/MainForm.yyc              用户代码与事件逻辑
```

文件必须同目录、同主名。完整职责和保存流程见 [三文件界面架构](architecture.md)。

## 使用方式

1. 点击“程序 → 新建 → 新建窗口”，或按 `Ctrl+Shift+N`。
2. 从右侧“窗口组件箱”单击组件后拖到窗体；双击组件箱图标可直接放置。
3. 单控件时拖动位置、拖动八个手柄调整尺寸；多选后可对齐、分布和属性批量编辑。
4. 在右侧“属性”夹修改控件名称、标题、图标、坐标、尺寸、颜色、字体和状态。
5. 按 `Delete` 删除控件，方向键微移 1 像素，`Shift+方向键` 微移 10 像素；`Ctrl+Z` / `Ctrl+Y` 撤销重做。
6. 双击控件创建默认事件，或在属性夹事件下拉框选择事件。事件骨架只写入用户 `.yyc`。
7. 在用户代码中填写逻辑。按 `F5` 或 `Ctrl+Enter` 预览真实 Windows 窗口。
8. `Ctrl+S` 保存界面时自动补齐并重写 `.Designer.yyc`。

设计画布默认吸附 8 像素网格，可在系统配置中关闭。工作区采用现代浅色 IDE 外壳，同时保留易语言式的紧凑属性表、点阵画布、组件箱和程序数据树。

## `窗体.yyx`

界面文件使用 UTF-8 XML，根元素为 `窗体`，控件作为直接子元素。它只保存外观：

```xml
<?xml version="1.0" encoding="utf-8"?>
<yy:窗体 xmlns:yy="urn:yy-studio:form:1"
         标识="@id/主窗口"
         名称="主窗口"
         标题="客户登记"
         图标="@资源/图片/应用图标"
         宽="760"
         高="500"
         背景="#F4F7FB">
  <yy:文本 标识="@id/主窗口/标题标签"
          名称="标题标签"
          文本="客户信息"
          左="40" 上="32" 宽="240" 高="40"
          字号="24" 前景="#17212B" 背景="Transparent" />
  <yy:按钮 标识="@id/主窗口/保存按钮"
          名称="保存按钮"
          文本="保存客户"
          左="184" 上="272" 宽="130" 高="42" />
</yy:窗体>
```

`图标` 引用 `Resources/ids.xml` 中登记的资源标识。图片框的 `图片` 属性同样使用 `@资源/图片/名称`，避免在界面文件中写死项目绝对路径。

界面 XML 禁止出现：

- 窗体 `代码`、`载入`、`关闭` 属性；
- 控件 `单击`、`文本改变`、`选择改变`、`选中改变` 属性；
- 子程序、变量、赋值或任何业务数据。

这些内容分别属于 `.Designer.yyc` 和 `.yyc`。违反规则会得到明确的格式诊断。

## 窗体字段

| 属性 | 必需 | 说明 |
|---|---|---|
| `标识` | 是 | 自动生成的稳定窗体标识，格式为 `@id/窗体名` |
| `名称` | 是 | 窗体类型名，必须是有效标识符 |
| `标题` | 否 | 窗口标题，默认“易语窗体” |
| `图标` | 否 | `Resources/ids.xml` 中登记的图片资源标识 |
| `宽`、`高` | 否 | 初始尺寸，宽 320–3840、高 240–2160 |
| `背景` | 否 | 颜色文本，例如 `#F4F7FB` 或 `Transparent` |
| `边框` | 否 | `可调边框`、`对话框边框`、`无边框` |
| `可否移动` | 否 | `真` / `假` |
| `初始位置` | 否 | `默认`、`居中显示`、`最小化`、`最大化` |
| `最小化按钮`、`最大化按钮` | 否 | `真` / `假` |
| `备注` | 否 | 设计说明，不生成运行逻辑 |

## 控件通用字段

| 属性 | 说明 |
|---|---|
| `标识` | 自动生成的稳定控件标识，格式为 `@id/窗体名/控件名` |
| `名称` | 控件唯一标识，也是代码中的控件对象名 |
| `文本` | 标题、内容或列表初值 |
| `左`、`上` | 相对窗体左上角的位置 |
| `宽`、`高` | 控件尺寸 |
| `字号` | 6 到 96 |
| `前景`、`背景` | 颜色文本 |
| `启用`、`可见` | 运行状态 |
| `选中` | 复选框或单选框初始状态 |
| `只读`、`多行`、`密码`、`最大长度` | 输入框属性 |
| `图片` | 图片框资源标识，例如 `@资源/图片/客户图标` |
| `数据表`、`数据列` | 数据绑定字段 |

当前控件类型：`按钮`、`文本`、`输入框`、`单选框`、`复选框`、`下拉框`、`列表框`、`分组框`、`图片框`。

`下拉框` 和 `列表框` 的 `文本` 使用中文或英文逗号分隔初始项目。

## 事件关系

事件关系保存在自动生成的纯代码 `.Designer.yyc`。文件中使用 `界面()`、`控件()` 和 `绑定()` 声明，不保存 XML。项目加载会拒绝缺少关系文件的可视化窗体。

支持的关系事件：

| 来源 | 事件 |
|---|---|
| 窗体 | `载入`、`关闭` |
| 按钮 | `单击` |
| 输入框 | `文本改变` |
| 复选框、单选框 | `选中改变` |
| 下拉框、列表框 | `选择改变` |

默认处理程序采用 `_` + 控件名 + `_` + 事件显示名，例如 `_保存按钮_被单击`。

用户代码可以通过稳定 ID 获取界面上下文：

```text
.程序集 主窗口代码
导入包 "系统.界面"

取控件("@id/主窗口/保存按钮").文本 = "已保存"
```

`取控件` 在预览和编译后的 Windows 窗口中使用同一映射：预览返回当前控件对象，编译产物从生成窗体 ID 字典中解析控件。

## 校验

- 根元素必须是 `窗体`。
- 名称必须是有效标识符；同一窗体中控件名不能重复。
- 窗体和控件标识必须与当前名称一致，并且不能与其他标识重复。
- 未知控件类型会阻止加载，避免静默丢失界面。
- 坐标、尺寸、字体和布尔值会校验。
- 界面 XML 包含事件或代码关系时会拒绝加载。
- 关系文件引用不存在的控件、类型不一致或同一事件重复绑定时会拒绝加载。
- XML 错误和关系错误均包含行列号。
- 窗体图标和图片框引用的资源必须在 `Resources/ids.xml` 中真实存在。

## 当前边界

固定坐标布局已支持移动、缩放、属性、事件和预览。以下仍在路线图中：

- 嵌套容器、布局约束和锚定。
- 更多系统控件、属性夹内嵌资源选择器和主题模板。
- 强类型控件成员与双向数据绑定。
- 多窗体之间的统一导航和数据传递 API。
