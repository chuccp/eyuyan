# 项目编译与独立 EXE

## 编辑器与编译器

项目提供两个独立入口：

| 程序 | 职责 |
|---|---|
| `YyStudio.exe` | WPF 可视化 IDE，用于项目、窗体、代码、预览和交互 |
| `yy.exe` | 命令行编译器，用于脚本、CI、构建和运行 |

`yy.exe` 只依赖无 WPF 的 `Yy.Compiler.dll`。IDE 编译按钮和命令行工具共用 `ProjectCompiler`、窗体解析、资源标识和 C# 代码生成实现。

## 命令行

```powershell
yy check <工程.yyproj|目录>
yy build <工程.yyproj|目录> [-o 输出.exe] [--framework-dependent] [--rid RID]
yy run <工程.yyproj|目录> [--framework-dependent] [--rid RID]
yy version
```

- `check` 校验工程清单、三文件结构、资源和语言代码，不生成 EXE。
- `build` 默认在当前目录生成工程清单指定的输出文件。
- `run` 在临时目录构建并启动程序，程序退出后清理临时产物。
- 默认目标为自包含 Windows x64 单文件；`--framework-dependent` 需要目标机安装 .NET 10 Desktop Runtime。
- 命令行编译器自身不要求安装 Studio，但当前构建链需要 .NET 10 SDK。

## 编译流程

易语项目是编译单元，不是把解释器和源码打进安装包：

```text
.yyproj 项目
  ├─ 入口 .yyc
  ├─ 模块 .yyc
  ├─ 窗体 .yyx
  ├─ 自动关系 .Designer.yyc
  ├─ 用户代码 .yyc
  └─ 资源
        ↓ 解析与语义加载
       AST
        ↓ 代码生成
  生成的 C# 窗体与函数
        ↓ .NET 编译
  独立 Windows 可执行文件
```

编译完成后不会嵌入 `.yyc` 或 `.yyx` 源文件供运行时重新解析，也不依赖原项目目录。生成的应用包含编译后的程序逻辑、已展开的窗体控件树、按标识解析并嵌入的图标/图片和自包含 Windows 运行时。

在 IDE 中打开 `.yyproj` 后使用默认快捷键 `Ctrl+B`，或点击“编译 EXE”。快捷键可由 `YyStudio.json` 覆盖。编译前会要求保存所有未保存的标签页。

## 编译产物

- 输出为单个 Windows x64 `.exe`。
- 独立版压缩自带 .NET 与 WPF 运行组件，目标机器不需要安装 .NET SDK。
- 启动时先运行项目入口，再打开 `.yyproj` 的 `启动窗体`。
- 按钮单击、窗体载入和关闭事件通过生成关系调用编译后的用户函数。
- 控件变量和对象属性访问在生成代码中直接落到 WPF 控件操作。
- 窗体 `图标` 通过 `@资源/图片/...` 解析并嵌入 EXE，窗口离开工程目录后仍可显示。
- 图片框 `图片` 使用相同资源标识解析；当前编译链已覆盖图标和图片框。

## 当前二进制级别

当前生成的是 **IL + Ready 运行时宿主** 的可执行文件，尚未做到纯机器码或 NativeAOT。WPF 当前不支持 NativeAOT，因此这仍是实际代码编译，但不是“零托管运行时”的原生后端。

后续原生计划：

1. 引入稳定中间表示（IR）和优化器。
2. 为无界面程序提供 NativeAOT 或 LLVM 后端。
3. 为窗体和控件提供 Win32/WinUI 原生后端，或等待 WPF NativeAOT 支持。
4. 建立解释执行、IL 编译、原生编译共享的语义测试集。

## 编译前置条件

编译需要开发机安装 .NET 10 SDK，并从项目仓库运行 IDE。编译器会把生成的应用项目临时发布为自包含单文件。

## 体积选项

默认构建使用压缩的自包含单文件，兼顾独立运行和体积。`.\build-lite.ps1` 额外生成精简版 IDE：

- 精简版体积明显更小。
- 目标机器必须预装 .NET 10 Desktop Runtime。
- 独立版无需目标机安装 .NET，但体积更大。

WPF 桌面运行时本身包含大量原生组件，因此低于几十 MB 的完全独立 WPF 单文件并不现实。需要在“体积”和“无依赖运行”之间选择。

编译后的用户程序不需要 SDK 或源码。当前测试矩阵已经覆盖：

- 项目代码生成与发布。
- 独立 EXE 启动。
- 启动窗体标题与控件树。
- 输入控件读取。
- 按钮事件调用用户代码。
- 事件修改界面并回读结果。
- 资源图标、图片框和 `Resources/ids.xml` 标识解析。
