# 功能现状与设计原则

## 产品定位

易语 Studio 是一个面向 Windows 的中文桌面开发环境。产品借鉴易语言“可视化窗体 + 中文代码 + 集成开发环境”的工作方式，同时采用现代 IDE 的项目结构、编辑体验和扩展接口。

核心目标是让以下路径保持连续：

```text
创建工程 → 设计窗体 → 放置控件 → 创建事件 → 编写代码 → F5 运行 → 编译 EXE
```

## 当前能力

| 方面 | 当前实现 |
|---|---|
| IDE 外壳 | WPF 原生窗口、自定义单条顶栏、贯穿高度的左右工具窗、中央编辑区下方控制台、文档标签、面包屑和状态栏 |
| 工具分离 | `YyStudio.exe` 提供 IDE，`yy.exe` 提供无 WPF 依赖的命令行构建、检查和运行 |
| 配置 | `YyStudio.json` 统一管理 MCP、编辑器、窗体和快捷键配置 |
| 工程模型 | `.yyproj` 清单、项目名/包名、`Sources/` 与 `Resources/`、源码/窗体/引用/资源和启动窗体 |
| 界面模型 | `.yyx`、纯代码 `.Designer.yyc`、`.yyc` 三文件结构，使用 `@id/...` 关联控件 |
| 资源系统 | `Resources/ids.xml`、图片/声音/文件分类目录、窗体和控件稳定标识 |
| 系统 SDK | 版本 1 包目录、成熟度与依赖校验、7 个可导入包、14 个自举/网络规划包、每包 `.yyc` 源码、默认核心包、跨 UI 契约和包候选补全 |
| 窗体设计 | 拖放、吸附、移动、八向缩放、多选、对齐、分布、属性编辑、撤销重做和预览 |
| 中文语言 | 中文标识符、函数、递归、默认参数、类型标注、数组、对象、异常、控制流和源码目录包导入 |
| 代码编辑 | 默认经典视图、纯代码模式、语法着色、补全、参数提示、F1 帮助、括号配对、折叠和快捷编辑 |
| 代码导航 | 对象/过程选择、窗体控件与事件导航、函数跳转、面包屑和行列定位 |
| 编译器 | `.yyproj → AST → Win64 机器码 → PE32+ 原生 EXE`，不存在 C#/WPF 应用后端 |
| 原生后端 | `yy build` 直接使用自研后端，支持隐式主程序和基础 Win32 窗口/按钮事件 |
| 资源编译 | 已建立资源索引和稳定 ID；图标、图片、声音等二进制嵌入仍待接入原生后端 |
| MCP | 19 个工具，可创建工程、导入资源、设计界面、写事件、预览、触发控件和截图 |
| 状态栏 | 运行状态、实际 MCP HTTP 地址（可点击复制）、光标位置和编码 |

## 编辑器体验

- 补全覆盖内置命令、关键字、用户子程序、窗体控件、控件属性、参数和局部变量。
- 输入 `.` 后按对象类型提供属性候选。
- 输入函数左括号后显示签名、当前参数序号和说明。
- `F1` 显示命令、函数、参数、变量或控件上下文。
- 括号、方括号、花括号和中英文引号自动配对。
- `Ctrl+Space` 打开补全，`Ctrl+/` 切换注释，`Ctrl+D` 复制行，`Ctrl+Shift+K` 删除行。
- 方法声明进入紧凑表格，执行语句保持连续代码画布。

## 工程与资源原则

- 用户逻辑只保存在 `.yyc`，界面 XML 不保存事件和业务数据。
- 新建工程必须填写项目名和包名，源码与资源分别进入 `Sources/`、`Resources/`。
- `引入 "项目包名.目录"` 按目录加载源码，点号映射 `Sources/` 下的目录层级。
- `.Designer.yyc` 与 `Resources/ids.xml` 都由工具生成并在编辑器中只读。
- 资源文件只能放在 `Resources/`，通过 `@资源/类型/名称` 引用。
- 窗体和控件使用 `@id/窗体/控件` 稳定标识，但 ID 只保存在生成关系中；用户代码使用控件名、窗口名和属性。
- 保存、F5 工程运行、设计预览和编译共用同一个资源解析流程。

## 质量原则

- 新增工程规则必须同步更新格式文档、示例和自动测试。
- 用户代码具有最高优先级，生成器可以补齐事件入口，但不能覆盖已有逻辑。
- 编译器、原生运行、设计预览和解释执行共享语言语义。
- IDE 中每个 MCP 操作都调用真实 UI 代码路径，不维护第二套文件写入逻辑。
- 手写源文件保持模块化，单个 C# 文件不得超过 900 行。

## 后续方向

- 更完整的静态类型、空值安全和跨模块符号分析。
- 更丰富的控件、布局容器、资源选择器和表单数据绑定。
- 原生值运行时、完整资源系统、增量编译和更完整的 Win32 控件矩阵。
- 完整调试协议、错误列表、全局搜索替换和安全重构。
- 类型/成员级包隔离、外部包管理、网络、数据库、图像与 Windows 互操作支持库。
