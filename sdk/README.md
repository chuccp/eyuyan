# 易语系统 SDK 源码

`Sources/` 是与 SDK 包名一一对应的 `.yyc` 公开源码目录。

```text
系统.基础            → Sources/系统/基础.yyc
系统.网络.HTTP       → Sources/系统/网络/HTTP.yyc
工具链.编译          → Sources/工具链/编译.yyc
```

语言核心包默认引用，不需要重复写 `导入包`。平台包和工具链包仍通过 `导入包 "包名"` 显式引用。

这些 `.yyc` 是系统 SDK 的公开声明和文档来源。内置实现由解释器与 Win64 原生后端提供，不会把 SDK 声明文件重复编译进用户程序。
