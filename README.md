# 易语 Studio

一个 Windows 原生、中文优先的现代易语言重制项目。它不是给旧代码换一套外观，而是以 VB、经典易语言和 Visual Studio 的“窗体设计器 + 属性 + 事件 + 代码后置”体验为参照，重建语言、运行时和桌面 IDE。

> **项目定位**
>
> 本项目旨在使用 AI 复刻易语言，探索 AI 驱动的中文编程语言、可视化开发环境与编译工具链。项目是非官方、独立重制实现，与易语言原作者及官方机构没有隶属关系；目标是延续中文编程的低门槛体验，同时加入现代软件工程能力。

当前仓库已经包含可运行的 MVP：

- C# / WPF 原生 Windows 桌面 IDE，无 Electron、无 WebView。
- 中文结构化代码、AST 解析器、IDE 解释执行器、C# 代码生成编译器、UTF-8、函数、递归、默认参数、类型标注、数组、对象和异常保护。
- 多标签编辑、`.yyproj` 项目入口、相对路径模块引入及跨文件诊断。
- VB/易语言式窗体设计器：工具箱、拖放控件、属性栏、多选对齐、撤销/重做、双击控件生成事件代码、`.yyx` XML 保存和原生窗口预览。
- 真实 `.yyproj` 项目、结构化 `.yyc` 入口源码、启动窗体、窗体资源与代码后置；控件及载入/关闭事件会执行对应代码并同步控件状态。
- 项目内新增源码、项目属性编辑，以及按钮、文本、选择、复选和窗体生命周期事件。
- 组件感知的代码编写：功能树直达事件、组件名与属性补全、结构化代码块、参数提示和 F1 上下文帮助。
- 项目可编译为不依赖源码目录、解释器或目标机 SDK 的自包含 Windows 单文件 EXE。
- 条件、`当`循环、`计次循环`、`遍历`、`跳出`、`继续`。
- 行号/列号诊断、可取消运行、JSON、字符串、集合和日期时间标准库。
- Visual Studio 风格原生暗色工作区、可拖动面板、原生代码编辑器、VS 语法配色、自动补全、查找、项目树、概要和变量面板。
- UTF-8 `.yyc` 结构化工程和可直接发布的 Windows x64 单文件程序；不提供旧版源码兼容层。

> 这是可运行的重制版基础，不兼容原版 `.e`/`.ey` 工程。纯机器码编译、数据库和 COM/API 支持仍在路线图中。功能边界见 [能力核对](docs/feature-analysis.md)。

完整规划、验收标准和当前状态统一维护在 [功能待办与路线图](docs/roadmap.md)，后续新增需求会继续补入该清单。

## 运行

需要 .NET 10 SDK 与 Windows 10/11。

```powershell
dotnet run --project .\src\Yy.Studio\Yy.Studio.csproj
```

打开 `examples` 文件夹即可加载示例工程。按 `F5` 运行当前源码或预览当前窗体，`Ctrl+F5` 运行项目入口，`Shift+F5` 停止，`Ctrl+S` 保存，`Ctrl+W` 关闭标签，`Ctrl+Space` 触发补全。窗体设计说明见 [`.yyx` 格式](docs/forms.md)。

打开项目时默认进入启动窗体设计器；在解决方案资源管理器中展开窗体可看到对应代码后置文件。双击按钮会自动创建或打开单击事件函数。

新建项目请按 `Ctrl+Alt+N`。项目目录、清单和代码后置关系见 [项目结构](docs/projects.md)。
按 `Ctrl+B` 编译项目为独立 EXE，内部实现与当前二进制边界见 [项目编译](docs/compiler.md)。
代码编写、组件关联和事件导航见 [代码编辑器](docs/code-editor.md)。`.yyc` 结构和事件索引见 [结构化代码格式](docs/code-format.md)。

## 构建发布版

```powershell
.\build.ps1
```

发布结果：

```text
artifacts\publish\YyStudio\YyStudio.exe
artifacts\samples\易语示例.exe
```

脚本会运行语言测试、编译链烟雾测试，再生成 IDE、编译示例项目，并输出可直接运行的 Windows x64 自包含单文件。

如果更在意体积，可以生成需要 .NET 10 Desktop Runtime 的精简版：

```powershell
.\build-lite.ps1
```

## 代码示例

`.yyc` 保存结构化命令，而不是整块纯文本源码。IDE 将下列 XML 显示为可展开的命令行：

```xml
<代码 格式版本="1" 名称="示例">
  <子程序 名称="问候" 返回类型="文本">
    <参数 名称="姓名" 类型="文本" />
    <返回 值="&quot;你好，&quot; + 姓名" />
  </子程序>
  <入口>
    <调用 值="输出(问候(&quot;世界&quot;))" />
  </入口>
</代码>
```

命令中的表达式仍使用中文易语语法。完整说明见 [语言参考](docs/language.md) 和 [代码编辑器](docs/code-editor.md)。

## 项目结构

```text
src/Yy.Language/       词法、语法树、解析器、解释器、中文标准库
src/Yy.CompilerRuntime/ 编译后程序使用的值、控件与标准库运行时
src/Yy.Studio/         WPF 原生 IDE
tools/YyCompiler.Cli/  命令行项目编译器
tests/Yy.Language.Tests/ 语言内核回归测试
examples/              可打开的易语示例工程
docs/                  能力分析、格式规范和语言参考
```

## 设计原则

1. **原生优先**：桌面端使用 Windows WPF，不引入浏览器运行时。
2. **中文不等于不可靠**：中文标识符与现代工具链、错误定位和测试可以同时存在。
3. **格式边界明确**：只支持自有 `.yyproj`、`.yyx`、`.yyc`，不读取或伪装旧版工程格式。
4. **渐进式现代化**：先打通语言与 IDE 主链路，再加入静态类型、调试器、原生编译和窗体设计器。
