# 易语 Studio

一个 Windows 原生、中文优先的现代易语言重制项目。它不是给旧代码换一套外观，而是以经典易语言的低门槛表达和一体化开发体验为参照，重建语言、运行时和桌面 IDE。

当前仓库已经包含可运行的 MVP：

- C# / WPF 原生 Windows 桌面 IDE，无 Electron、无 WebView。
- 中文源码解析器、IDE 解释执行器、C# 代码生成编译器、UTF-8、函数、递归、默认参数、类型标注、数组、对象和异常保护。
- 多标签编辑、`.yyproj` 项目入口、相对路径模块引入及跨文件诊断。
- 原生窗体设计器：拖放控件、移动、八向缩放、属性编辑、撤销/重做、`.yyx` XML 保存和原生窗口预览。
- 真实 `.yyproj` 项目、入口源码、启动窗体、窗体资源与 `.ey` 代码后置；控件及载入/关闭事件会执行对应代码并同步控件状态。
- 项目可编译为不依赖源码目录、解释器或目标机 SDK 的自包含 Windows 单文件 EXE。
- 条件、`当`循环、`计次循环`、`遍历`、`跳出`、`继续`。
- 行号/列号诊断、可取消运行、JSON、字符串、集合和日期时间标准库。
- 原生代码编辑器、语法高亮、自动补全、查找、项目树、概要、变量和标准库面板。
- UTF-8 `.ey` 文本工程和可直接发布的 Windows x64 单文件程序。

> 这是可运行的重制版基础，不是“100% 易语言兼容”的完成品。原版 `.e` 工程导入、纯机器码编译、数据库和 COM/API 支持仍在路线图中。功能边界见 [能力核对](docs/feature-analysis.md)。

完整规划、验收标准和当前状态统一维护在 [功能待办与路线图](docs/roadmap.md)，后续新增需求会继续补入该清单。

## 运行

需要 .NET 10 SDK 与 Windows 10/11。

```powershell
dotnet run --project .\src\Yy.Studio\Yy.Studio.csproj
```

打开 `examples` 文件夹即可加载示例工程。按 `F5` 运行当前源码或预览当前窗体，`Ctrl+F5` 运行项目入口，`Shift+F5` 停止，`Ctrl+S` 保存，`Ctrl+W` 关闭标签，`Ctrl+Space` 触发补全。窗体设计说明见 [`.yyx` 格式](docs/forms.md)。

新建项目请按 `Ctrl+Alt+N`。项目目录、清单和代码后置关系见 [项目结构](docs/projects.md)。
按 `Ctrl+B` 编译项目为独立 EXE，内部实现与当前二进制边界见 [项目编译](docs/compiler.md)。

## 构建发布版

```powershell
.\build.ps1
```

发布结果：

```text
artifacts\publish\YyStudio\YyStudio.exe
artifacts\samples\易语示例.exe
```

脚本会运行语言测试、编译链烟雾测试，再生成 IDE、编译示例项目，并输出可直接运行的 Windows x64 自包含单文件。

## 语言示例

```text
.版本 3
.程序集 示例

子程序 问候(姓名, 前缀 = "你好")
    返回 前缀 + "，" + 姓名
结束子程序

变量 用户 = {姓名: "世界", 数字: [1, 2, 3]}
输出(问候(用户.姓名))

遍历 值 于 用户.数字
    输出(值)
结束遍历
```

完整语法见 [语言参考](docs/language.md)。

## 项目结构

```text
src/Yy.Language/       词法、语法树、解析器、解释器、中文标准库
src/Yy.CompilerRuntime/ 编译后程序使用的值、控件与标准库运行时
src/Yy.Studio/         WPF 原生 IDE
tools/YyCompiler.Cli/  命令行项目编译器
tests/Yy.Language.Tests/ 语言内核回归测试
examples/              可打开的易语示例工程
docs/                  能力分析、兼容策略和语言参考
```

## 设计原则

1. **原生优先**：桌面端使用 Windows WPF，不引入浏览器运行时。
2. **中文不等于不可靠**：中文标识符与现代工具链、错误定位和测试可以同时存在。
3. **兼容要可验证**：不宣称读取未公开的 `.e` 格式；迁移必须有映射、诊断和回归用例。
4. **渐进式现代化**：先打通语言与 IDE 主链路，再加入静态类型、调试器、原生编译和窗体设计器。
